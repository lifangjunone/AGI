# Novel Series Factory

面向小说、网文和原创故事的 AI 全集视频生产平台。

产品目标不是生成一条“看起来像视频”的片段，而是把小说稳定地加工成角色统一、剧情连续、音画同步、可批量交付的完整剧集。

## 商业 Beta 桌面应用

```bash
cd /Users/bytedance/Desktop/agi/novel-series-factory
npm start
```

`npm start` 会启动 Electron 桌面应用和仅供本机桌面会话访问的制作服务。当前
商业 Beta 已实现从故事来源、动态分集、制片资产、逐集生产、质量门禁到商业交付的
完整产品流程：

```text
小说正文 / 小说地址 / AI 原创描述
→ AI 故事分析与动态分集
→ 人物四视图、场景、武器道具、固定角色音色
→ 连续性账本与逐集生成
→ 音画、字幕、声音与视觉一致性质量门禁
→ 全集合成与商业交付包
```

真实图像或视频模型调用可能产生费用，必须在“制片配置”中显式开启，并在每次全集
生产前确认集数与费用。已完成且通过质量门禁的分集会被保留，恢复生产时不会重复生成
或重复计费。

## 模型配置

- 本地密钥保存在 `.env.local`，该文件已加入项目级 `.gitignore`。
- 可提交的配置模板为 `.env.example`。
- 模型能力、路由和兜底顺序定义在 `config/models.json`。
- 可选 `REFERENCE_ENV_FILE` 从既有项目读取 ASR、时间戳和重排等配置，本项目 `.env.local` 始终具有更高优先级。
- 脱敏状态接口：`GET /api/models/status`。接口分别返回“配置完整”和“运行可用”，
  不返回密钥。`?refresh=1` 会重新执行安全的运行检查。
- 多模态健康检查只执行最小图片理解请求，不调用图像生成或视频生成，并缓存 5 分钟。
- 专用多模态 endpoint 不可用时，会真实探测语言模型的图片理解能力；只有探测通过
  才允许它接管成片一致性质检，并在界面与质量报告中记录实际生效模型。
- `ALLOW_BILLABLE_GENERATION=false` 时禁止真实付费生成。

当前路由：

- 故事理解、剧本创作：方舟语言模型；
- 镜头与成片复核：方舟多模态模型；
- 角色和分镜图：Seedream；
- 主视频生成：Seedance；
- 视频生成兜底：OpenAI 兼容 Base64 MP4 接口；
- ASR：SeedASR；
- TTS：GPU 开发机自托管 Qwen3-TTS 1.7B，支持角色音色、情绪指令和授权声音克隆；
- 字幕时间戳、剧情检索：复用参考项目中的辅助模型。

## 建议的首个产品形态

优先做“AI 漫剧 / 动态漫批量工作台”，首期聚焦：

- 中文网络小说或原创故事；
- 竖屏 9:16；
- 单集 1–3 分钟；
- 每部 20–100 集；
- 以旁白、角色对白、分镜图片、局部动态和音效合成为主；
- 人工审核关键节点，其余流程自动批处理。

相比直接追求全真人级长视频，这一形态更容易保证角色一致性、生产稳定性和可控成本，也更适合作为后续升级到高动态视频或真人短剧的生产底座。
