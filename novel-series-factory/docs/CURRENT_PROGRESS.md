## 已发现的问题

按优先级处理：

### 已修复：URL 来源类型在导入成功后丢失

位置：

- `lib/mvp-pipeline.mjs` 的 `createPlan`
- `public/studio.js` 的 `refreshProject`

原因：

`createPlan` 抓取 URL 后把 `input.sourceType` 改写为 `manual`，并将改写后的类型持久化。
前端以 `project.input.sourceType === "url"` 判断是否隐藏生成按钮，因此 URL 项目被误认为手工正文项目。

当前实现：

- 持久化 `sourceType: "url"` 作为原始来源类型。
- 使用 `resolvedContent` / `effectiveSourceType` 表示已经解析出的正文。
- 生成资格判断读取正文是否已解析，不再通过来源类型间接判断。

### 已完成：真实视频端到端验证

正式数据中保留了两集、每集约 10 秒的 Seedance 真实成片，包含：

- 人物四视图、场景、道具和固定角色音色参考输入。
- 第 2 集使用第 1 集视频作为 `extend` 跨集续写参考。
- 两集均有可播放 MP4、SRT、故事结构、连续性账本与模型任务 ID。
- 两集均已使用“现有媒体重新验收”完成 FFmpeg、语音/字幕溯源和真实视觉一致性
  门禁，不重新调用视频生成模型。
- 视觉质检实际使用已验证可看图的 `glm-5-2-260617` 后备模型；两集报告均通过，
  分别记录 0.85/0.9 置信度。

### 已修复：分集算法严重高估

12,000 字、动漫、单集 90 秒被规划为 81 集。

相关代码：

- `lib/mvp-pipeline.mjs` 的 `deriveEpisodePlan`
- 当前按 `duration * 3.2 * narrationRatio` 计算单集容量。

问题：

- 把“旁白占比”用于降低可承载字数后，集数被成倍放大。
- URL 页面截取的 12,000 字只是作品片段，却被当成完整作品体量。
- 英文字符数直接套用中文口播速度。

当前实现：

- 中文按汉字、英文按单词分别计量，标点和空白不再放大内容体量。
- 估算使用“可改编原文容量”，不再把全部原文误当成逐字旁白。
- 12,000 中文字符、90 秒动漫从原来的 81 集降为约 11 集。
- URL 导入区分公开章节样本、作品简介、截断片段和当前网页正文。
- 章节或截断样本会明确提示“不是整本书最终集数”。
- AI 剧情描述维持最少三集的故事弧估算，并标记为暂定。

仍待增强：

- 以章节、场景和情节点为主要切分边界，当前原文偏移仍采用等容量连续范围。
- 增加用户调整集数后重新分集和影响范围预览。

## 当前产品设计：小说内容按集展示

用户已确认希望“小说内容分集按集展示”。建议采用桌面端三栏联动布局：

```text
┌──────────────┬──────────────────────────────┬────────────────────┐
│ 集数导航      │ 本集原文                      │ 本集改编与制作状态   │
│              │                              │                    │
│ 01 迷雾初现   │ 第 1 章 ……                    │ 摘要 / 角色 / 场景   │
│ 02 无名尸骨   │ 高亮本集采用的原文范围          │ 时长 / 镜头 / 状态   │
│ 03 西市疑云   │ 可显示前后少量上下文             │ 重新划分 / 生成本集   │
└──────────────┴──────────────────────────────┴────────────────────┘
```

### 交互要求

- 左栏按集展示序号、标题、对应章节、预计时长和制作状态。
- 中栏展示本集引用的原文，保留段落和章节结构。
- 右栏展示本集摘要、关键人物、场景、道具、悬念点和制作状态。
- 点击集数后三栏同步切换。
- 支持上一集/下一集及键盘方向键。
- 支持“只看原文”“原文 + 改编对照”“制作信息”三种密度。
- 明确显示原文覆盖率，避免漏段和重复分配。
- 允许用户调整本集起止边界；保存前显示会影响的后续剧本、资产和成片。
- 手机端改为顶部集数选择器，正文和制作信息纵向排列。

### 需要补充的数据

当前 `seriesPlan.episodes` 只有标题和摘要。建议每集新增：

```json
{
  "number": 1,
  "title": "第一集标题",
  "summary": "本集摘要",
  "source": {
    "chapterStart": "第一章",
    "chapterEnd": "第二章",
    "startOffset": 0,
    "endOffset": 1840,
    "excerpt": "本集对应原文",
    "characterCount": 1840
  },
  "storyBeats": [],
  "characters": [],
  "scenes": [],
  "props": [],
  "cliffhanger": "",
  "estimatedDurationSeconds": 90
}
```

不要只保存 `excerpt`；必须保留稳定的原文范围或段落 ID，避免重新分析后无法追溯。
