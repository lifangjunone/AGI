# FDE 前线工程手册

面向中文读者的 Forward Deployed Engineer（前线部署工程师）交互式岗位手册。项目同时提供快速岗位认知、完整工作方法、能力地图、90 天入行路径和可评分的制造业部署实战。

## 内容

- 60 秒岗位定义与 FDE、产品工程师、解决方案工程师、技术顾问对比
- 从发现、定界、共建、投产到产品回流的五阶段方法
- 工程交付、AI 系统、客户共创和产品判断四类能力
- 三阶段制造业设备告警实战，包含即时反馈和结果评分
- 90 天作品集路线、面试信号、适配度判断与延伸资料
- 全局搜索、移动端导航、键盘访问和减少动态效果支持

## 运行

```bash
npm install
npm run dev
```

开发地址默认为：

```text
http://127.0.0.1:5173
```

构建生产版本：

```bash
npm run build
```

## 资料原则

岗位定义优先采用公司官方招聘资料，社区资料只用于补充实践路径。页面内保留原始来源与核验日期。FDE 在不同公司可能叫 FDSE、Forward Deployed AI Engineer 或 Deployment Engineer，应以实际职责而非职位名称判断。
