# 产品定义

## 愿景

极致的视频处理、理解、生成。

叙镜的核心对象不是单条成片，而是带时间码、来源和关系的“叙事资产”。系统先回答视频里发生了什么、证据在哪里，再支持二创、裂变和生成。

## 核心原则

1. **证据优先**：每个故事判断、高光和人物关系都必须回到时间码、画面、对白或音频证据。
2. **理解先于生成**：生成任务消费统一的理解结果，避免每个工具重复解析原片。
3. **前贴不是摘要**：前贴是独立成立、能自然压入正片入口的短内容。
4. **钩子可实验**：钩子应支持受众、强度、节奏和信息差维度的变体与评分。
5. **创作可控**：模型提供候选方案，创作者决定片段、顺序、文案和输出规格。

## 五个工作台

### 视频理解

- 故事摘要、情绪曲线、人物关系和关键情节
- 逐段转写、高光片段、对应音频与高光帧
- 语义检索并跳转到可验证的时间码证据

### 视频二创

- 选择高光优先、冲突前置、人物线等重组策略
- 配置画幅、节奏、字幕与声音处理
- 在生成前编辑候选轨道

### 视频裂变

- 组合受众、画幅、时长和开场方式
- 控制批量变体规模
- 对结果做去重、质量过滤和实验分组

### 生成前贴

- 基于原片入口设计独立的前置故事
- 输出文案、镜头、情绪转折和衔接点
- 保持主角、世界观与正片入口一致

### 黄金钩子

- 聚焦前 5 秒，并在 1–2 秒内制造情绪转折
- 生成信息差、关系反转、倒计时等候选
- 支持评分、比较和一键复制

## MVP 与生产边界

| 范围 | 当前原型 | 生产版本 |
| --- | --- | --- |
| 上传与预览 | 服务端磁盘上传与流式预览 | 分片上传、对象存储、转码代理 |
| 视频理解 | SeedASR + Ark MM + Neo4j 真实链路 | OCR、镜头检测、说话人/人脸跨镜追踪 |
| 语义检索 | 本地关键词过滤 | 向量检索、GraphRAG、时间码引用 |
| 二创与裂变 | 参数和轨道交互 | FFmpeg/渲染集群、模板执行、任务队列 |
| 前贴与钩子 | 规则化候选文本 | 多模型生成、品牌约束、自动评测 |
| 数据 | 服务端 JSON 状态 + Neo4j，localStorage 保存当前会话 | 项目数据库、版本、权限、审计 |

## 首个生产闭环

上传 1 条视频后，在 3 分钟内得到带证据的理解结果；选择一个高光后生成 3 个钩子和 3 个竖屏变体；预览、修改并导出。优先验证“理解结果是否可信”和“生成结果是否值得发布”，不先扩展社区或素材市场。
