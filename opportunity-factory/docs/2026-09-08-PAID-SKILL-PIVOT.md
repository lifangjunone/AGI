# Opportunity Factory 商业转向：AI POC 验收审计 Pay Skill

日期：2026-09-08

## 结论

停止把“GitHub 开源项目生产采用审计”作为主产品。新产品为：

> 政企 AI POC 验收与投标应答审计：把招标文件、需求书或 POC 要求转成可执行、可追踪、可验收的交付矩阵。

首发渠道为 SkillHub Pay Skill，首发验证价为 ¥1.99/项目。完成 20 笔陌生用户订单后测试 ¥5/次。

## 为什么不是原方向

原方向的问题不是页面或支付按钮，而是需求链路错误：

1. GitHub 浏览者多数没有企业采购权限，访问意图和付款意图脱节。
2. “开源项目审计报告”容易被通用模型和免费工具替代。
3. 独立网站没有自然分发，已有生产数据为 5 次有效访问、0 次审计、0 笔付款。
4. 个人微信收款码没有官方可用的支付回调，无法自动验付和自动交付。

## 市场证据

### 支付与分发基础设施已经成立

- SkillHub Pay Skill 支持按次收费、任务内支付、自动核验、自动交付和实时结算：
  <https://skillhub.cn/skillpay>
- SkillHub 官方列表已经有约 2,100 个 Pay Skill：
  <https://skillhub.cn/skills?category=pay-skill&sortBy=score>
- “知了标讯”在 SkillHub 页面显示 101.4 万平台数据，“招投标超级大师”显示 1.1 万，并以 ¥5/次提供招标提取、建议书编写和投标检查。这证明招投标工作流在 Agent 入口内存在真实使用：
  <https://skillhub.cn/skills/org-32m5yxyy/zlbx-bidding-payskill>
  <https://skillhub.cn/skills/org-ffjpn5v1/bidding-super-master>
- 腾讯官方说明 SkillPay 将技能分发、Agent 调用与支付打通，商家保留定价权和收款权：
  <https://news.qq.com/rain/a/20260716A09SXS00>

### 个人自动收款的现实边界

- SkillHub 个人接入目前开放支付宝 A2M 按量付费，无需营业执照，支持 402、验付和履约确认：
  <https://skillhub.cn/tutorials#alipay-pay>
- SkillHub 微信通道需要企业认证、微信商户号和标准微信支付下单能力：
  <https://skillhub.cn/tutorials#agent-pay-onboard>
- 微信官方“个人收款交易支付通知”仍处于灰度、暂未开放，不能把个人微信二维码包装成全自动支付：
  <https://pay.weixin.qq.com/doc/v3/partner/4012602261>

因此首发使用个人支付宝自动结算；取得企业商户资质后增加微信通道。个人微信码仅保留人工备选，不再被定义为自动闭环。

## 目标用户

- 政企 AI 项目的售前解决方案、产品经理、测试负责人。
- 参与国央企 AI POC、招投标或多厂商竞标的集成商。
- 需要把模糊需求变成验收条件、测试步骤和证据材料的项目团队。

用户付费购买的不是文本，而是降低三类损失：

- 漏项导致失分或废标。
- POC 现场无法复现、无法举证。
- 需求、测试、证据和应答之间不可追踪。

## 付费交付物

每次调用处理一个项目，输出：

1. 需求追踪矩阵：原文条款、需求类型、优先级、验收指标、责任角色。
2. POC 测试用例：前置条件、步骤、数据、预期结果、失败判据。
3. 证据清单：截图、日志、报表、配置、签字材料及采集时机。
4. 演示脚本：按业务价值组织，而不是按产品菜单组织。
5. 风险缺口：硬门槛、歧义、依赖、不可测项、交付风险及修复建议。
6. 投标应答审查：逐条覆盖状态、证据位置、矛盾与遗漏。

所有无法从用户材料证明的内容必须标为“待确认”，禁止虚构指标、案例或资质。

## 自动赚钱飞轮

```text
SkillHub 搜索/Agent 意图命中
  -> 免费看到明确输入、输出和案例
  -> ¥1.99 任务内付款
  -> 自动验付
  -> 自动生成六件套
  -> 用户对下一个标段/POC 重复调用
  -> 完成率、复购率、评分提升 SkillHub 排名
  -> 更多自然调用
```

辅助增长：

- 发布 3 个脱敏合成案例：知识库问答 POC、智能客服 POC、Agent 平台 POC。
- 免费发布“AI POC 需求自检”普通 Skill，只输出 5 个高风险项，完整矩阵转入 Pay Skill。
- 每次成功履约记录品类、输入规模、耗时、结果下载和 7 日复购，不保存客户原文。

首发阶段：

|---|---:|
| 单次价格 | ¥1.99 |
| 单次模型成本 | 接近 ¥0，由调用 Agent 执行分析 |
| 单次服务端成本 | < ¥0.05 |

价格验证：

- 0-20 笔：¥1.99，验证付款和履约。
- 21-100 笔：A/B 测试 ¥5。
- 有稳定复购后：增加 ¥19.9 深度版，包含 Word/Excel 文件和跨文档一致性检查。

## 验证门槛与止损

14 天内：

- SkillHub 展示 >= 500；
- 详情访问 >= 50；
- 付费调用 >= 10；
- 成功履约率 >= 95%；
- 7 日复购 >= 20%；
- 退款率 < 5%。

决策规则：

- 有展示、无调用：重写名称、触发词、案例或降价。
- 有付款、无复购：交付结果不够有用，先修产品。
- 履约失败：立即停止推广，修复支付或生成链路。
- 展示不足 500：渠道未被验证，不能据此否定需求。
- 达到 20 笔且复购 >= 20%：提价并增加微信企业通道。

## 不做什么

- 不宣称保证中标、保证通过验收或保证赚钱。
- 不抓取、群发或骚扰潜在客户。
- 不使用个人微信监听、逆向协议或“免签支付”。
- 不保存原始招标文件；默认任务结束即删除临时内容。
- 不继续为旧 GitHub 审计产品增加功能。
