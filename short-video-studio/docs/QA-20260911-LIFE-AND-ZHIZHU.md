## 未通过与原因

### 1. 小程序公众号文章助手 WebView 无法打开

现象：

```text
无法打开该页面
不支持打开 https://www.lifeyoume.icu/video/zhizhu/?from=miniapp&tool=article
```

原因：微信小程序的业务域名/`web-view` 合法域名尚未完成配置，代码本身的 URL 使用的是生产 `www` 域名。

处理方式：

```text
微信公众平台
→ 开发
→ 开发管理
→ 开发设置
→ 业务域名
```

添加：

```text
https://www.lifeyoume.icu
```

保存并重新上传体验版。配置完成前，不能宣称小程序文章助手可用。

### 2. 小程序完成通知入口缺少任务编号

当前页面从“我的”直接打开时没有 `jobId`，点击开启通知会提示“缺少任务编号”。通知接口设计要求从具体视频任务页面携带任务编号进入。

后续应将入口改为：

```text
视频任务详情
→ 生成完成通知
→ 携带 jobId 订阅
```

### 3. Web 支付解锁仍为禁用状态

Web 页面按钮显示为 disabled，页面明确提示支付能力接入后开放。这是当前产品策略，不属于静默失败，但代表 Web 端不能完成支付闭环；微信虚拟支付仅在小程序正式线上版验证。
