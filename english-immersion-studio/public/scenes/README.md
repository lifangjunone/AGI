# Local Scene Library

These six 1024 x 576 environment images were generated locally with
`mlx-community/flux2-klein-4b-4bit` through `mflux 0.19.1`.

The fixed seeds and prompts are recorded in
`scripts/generate-scene-library.sh`. All scenes intentionally contain no
people, logos, watermarks, or visible text so the live 3D character remains
the only conversation partner.
