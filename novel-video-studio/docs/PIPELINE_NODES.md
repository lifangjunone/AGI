# 固定流水线与节点产物

## 来源确认门禁

创建任务后，系统只执行 `NODE 01 全网检索`。检索结果会停在 `source-review`，不会读取正文或调用后续生成模型。

候选来源包含：

- 作品名、作者、出版年份与语言
- Project Gutenberg、Open Library、Google Books 或公版目录来源
- 标题匹配度与版权状态
- 全文、内容梗概或仅元数据标记
- 可打开核验的原始来源链接

`NODE 01` 同时保存逐源检索轨迹：

- 检索源名称与类型
- 实际查询 URL
- `completed / degraded / failed / skipped` 状态
- 候选命中数与耗时
- WAF、限流、超时或未配置凭据等错误

国内检索默认执行 360 全网查询，并对 `config/novel-sources.json` 中的每个启用域名单独执行站内查询。站点可在应用内增删或停用，结果持久化到数据目录的 `search-sources.json`。精确目录候选在上游搜索受限时仍可降级命中。

用户确认具体来源后，任务重新进入生产队列，从 `NODE 02 内容核验` 继续。如果所选来源没有可处理版权，任务进入 `rights-review`，可返回来源库重新选择。

## 六个固定节点

| Node | 名称 | 输入 | 主要产物 |
| --- | --- | --- | --- |
| 01 | 全网检索 | 小说名、检索策略、来源配置 | 逐源查询轨迹、候选版本、推荐来源、作者、版权、匹配度 |
| 02 | 内容核验 | 已确认来源 | 正文字数、内容预览、版权结果、降级方式 |
| 03 | 剧本改编 | 正文或梗概、目标时长 | 故事基调、梗概、人物、武器、地点、分集脚本 |
| 04 | 视觉设定 | 连续性设定 | 角色、武器、场景图片与提示词 |
| 05 | 镜头渲染 | 镜头计划、并发配置 | 每个镜头的提示词、状态、进度和视频地址 |
| 06 | 成片装配 | 镜头文件、时长、编码器 | 成片地址、文件路径和最终时长 |

生产模式下，`NODE 03` 默认记录并调用规划模型 `glm-5-2-260617`，`NODE 05` 默认记录并调用 Seedance 2.5 模型 `doubao-seedance-2-5-260628`。两者均可通过服务端环境变量覆盖。

每个节点持久化：

- `status`: `pending / running / completed / paused / failed`
- `startedAt` 与 `completedAt`
- 结构化 `input`
- 结构化 `output`
- 节点错误 `error`

生产总览中的六个节点均可点击。历史任务会优先读取持久化节点记录；旧任务没有节点记录时，根据已有来源、剧本、资产、镜头和成片数据生成只读摘要。
