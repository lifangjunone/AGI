# 任务中心与并发调度

## 项目并发与连续片段串行

| 层级 | 默认值 | 配置 | 作用 |
| --- | ---: | --- | --- |
| 小说项目 | 2 | `MAX_PROJECT_CONCURRENCY` | 限制同时运行的整书生产流水线 |
| 单项目连续片段 | 1 | 固定 | 同一项目同一时间只提交或轮询一个片段，保证尾帧可以传给下一片段 |

默认最多同时占用 2 个远端视频任务，分别属于两个独立小说项目。项目槽满后，新项目保持 `queued`，不会提前发起付费模型调用。历史配置项 `MAX_VIDEO_CONCURRENCY` 仅为旧项目兼容保留，不改变连续片段的串行约束。

## 状态模型

| 状态 | 含义 | 是否占用项目槽 |
| --- | --- | --- |
| `queued` | 已持久化，等待生产槽 | 否 |
| `running` | 来源检索、改编或视觉设计中 | 是 |
| `source-review` | 已找到候选作品，等待人工确认具体版本 | 否 |
| `season-review` | 全书分集规划已完成，等待选择本季连续范围 | 否 |
| `rendering` | 当前分集的一个连续片段正在生成或装配 | 是 |
| `completed` | 当前所选季的全部分集成片完成 | 否 |
| `failed` | 流水线失败，可重试 | 否 |
| `rights-review` | 版权门禁暂停 | 否 |
| `budget-gate` | 付费生成开关未开启 | 否 |

队列按进入时间先进先出。每个排队项目持久化 `queuePosition` 和 `estimatedWaitMinutes`；服务重启后，排队任务自动恢复，运行中但未进入远端渲染的任务重新排队，远端渲染任务继续轮询。片段失败时只重置失败或过期片段，已下载片段、尾帧和已完成分集不会重做。

## 项目中心

- 默认入口只展示项目组合，不自动打开最近任务。
- 支持创建项目、按名称搜索，并按全部、进行中、待处理、已完成筛选。
- 项目卡展示封面、状态、总体进度、六节点轨道、分集与镜头统计。
- 点击项目后进入项目上下文，才启用生产流水线、来源、资产和分集导航。
- 返回项目中心会退出当前项目上下文，并重新禁用项目级导航。

## 任务中心

- 展示项目槽、排队数量与空闲槽。
- 按全部、进行中、排队、已完成、异常筛选。
- 按书名、来源或任务 ID 搜索。
- 每次渲染最多 50 条历史记录，可继续加载。
- 点击历史任务恢复总览、来源、资产和分集详情。
- 排队任务显示位次、队列总数和预计等待时间。

## 设计参考

- Runway：项目化管理、短镜头生成与 Workflow 串联成长视频。
- Kling：创建异步任务、保存任务 ID、列表查询并持续轮询状态。
- HeyGen：持久化视频任务，支持列表、批量创建和批量状态查询。

这些模式被收敛为本项目的“项目任务中心 + 镜头子任务”结构，而不是把每个镜头直接暴露成不可管理的全局列表。
