# 今日时运卡片重设计

本轮只创建独立预览，不改线上已确认首页，也不将样例伪装成测算。

产品纠偏：静态人格卡 ≠ 今日时运。下一步正式生成必须使用 Asia/Shanghai 的
当日日期参与起卦；人格底盘和今日卦象应分开。不宣称规则生成等同专业命理。

交互：填写 → 新 URL/card 视图 → 从页顶揭晓 → 返回填写（保留输入）。
结果不再追加到首页底部。浏览器返回与页面返回一致。

三种构图同内容：

- 星盘卡：深靛蓝、金色六爻图与环形星盘，独立收藏卡 + 右侧解签。
- 玄符卡：墨绿金线、印章式边框，方圆叠合图形与纵排小印。
- 签笺卡：浅纸色、棕金线、窄签竖排签文，侧栏解签。

字体：中文宋体只用于签名/签文，正文黑体；签名 28px / 手机 27px。
配色：深靛 #152238，卡面 #1c3047，金 #dbc697，辅字 #c1d1dc；
玄符用 #17362f / #1c4137；签笺用 #eeeae1 / #fbf6e9。

避免巨字、英语营销标签、相同圆角模块堆砌。只把视觉表现放在签卡本身。
线条图用 SVG 实现，不需要生成图片资产。动画只用于进入揭晓，支持 reduced-motion。

未接：真实起卦、日期运算、付费、图片导出。预览按钮明确说明未接导出。
