# 今日小记

一个面向 macOS 的轻量每日待办桌面工具。数据只保存在本机，不需要账号或网络。

## 已实现

- 输入后按回车快速添加今日待办
- 完成、编辑、删除、置顶和设置提醒时间
- 待完成/已完成筛选与今日完成进度
- 菜单栏常驻，关闭窗口后提醒仍继续运行
- `Command + Shift + Space` 全局呼出并聚焦输入框
- `Esc` 快速隐藏
- 双击标题日期区折叠为 `286×46` 单行状态条，单击状态条恢复
- 折叠条可固定在当前显示器左上角或右上角，展开后保持同侧
- 青绿、暖黄、雾粉、浅蓝和白色五种纸张颜色
- 到期提醒，以及 11:00、15:00、19:00 的节奏提醒
- 智能提醒、窗口置顶和开机启动开关
- 本地 JSON 持久化，不上传任务内容

## 运行

```bash
npm install
npm start
```

## 验证

```bash
npm test
npm run pack
```

打包产物位于 `dist/mac-arm64/今日小记.app`。首次启动后，macOS 可能请求通知权限。
