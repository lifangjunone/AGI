# LifeYouMe / A：现代产品发现平台

北极星：让用户更快找到可用产品，让运营者区分真实兴趣与推广设置。

## 范围与约束

- 门户首页、目录、详情、管理后台和登录页面；不改独立子产品。
- 沿用 LY 标识、深绿品牌和已有注册、热度、轮转、访问控制。
- Python 服务端 HTML + 原生 CSS/JavaScript；无框架迁移与外部字体依赖。
- 保持严格 CSP；不加入内联样式或第三方脚本。

## 视觉与结构

- 浅灰绿色画布 #f6f8f7、白色表面、深绿操作色 #17634d。
- 中文系统无衬线，正文 16px、工具数据 14px、辅助文字不低于 12px。
- 8px 间距节奏，组件圆角 8–16px；颜色主要来自产品内容。
- 门户首屏：短标题、搜索、场景和可用范围筛选，随后是三列产品。
- 没有截图的产品用统一线性类别图标和真实能力说明，不伪造界面。
- FlowFrame 预览复用项目现有 studio-desktop.png，转换为 960px 内 WebP。
- 后台自然页面滚动；运营指标、用户兴趣榜、趋势、推广编辑依次展开。
- 热度 TOP 仅表示真实点击排名，展示徽章仅表示运营排序。
- 零点击不授予热度 TOP，暂无公开入口保持置底。

## 交互

- 目录分类、搜索、可用范围持久化到 URL，支持刷新、深链接和返回。
- 筛选重置可回到全部产品；没有结果显示明确说明。
- 后台搜索和分页在 sessionStorage 恢复。
- 服务端 POST/CSRF 继续作为事实来源；增强提交展示忙碌态。
- 失败保持输入和位置，错误就地显示，允许重试。
- 移动表格按字段标签重排为记录；导航换行而非水平溢出。
- 保留原生键盘、可见焦点、跳转主要内容、减少动态效果。
- 首次产品出场 300ms，按钮反馈与分区转换沿用短促动效。

## 标杆与取舍

查看 Vercel 和 Raycast 的实际首屏：借鉴前者清晰的字重层级、
有限强调色与可辨主操作；借鉴后者统一的控件语法和产品识别。
不借用其品牌色、装饰主视觉或营销横幅。LifeYouMe 是内容发现平台，
产品本身须在首屏，而非广告口号。

## 验收

375/390、768、1024、1440 宽度，200% 阅读与减少动态效果；
搜索、分类、零结果、刷新读回、后台保存读回与失败保留；
截图审查对比度、中文换行、长名称、CSP 和资源加载。
