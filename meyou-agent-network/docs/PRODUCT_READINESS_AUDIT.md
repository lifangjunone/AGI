## 验收原则

- 只展示数据库中的真实用户、圈子、消息、模型输出和在线状态。
- 每个入口必须有可完成的结果，不以“规划中”或静态卡片冒充功能。
- 每次异步操作都有加载、成功、失败与恢复路径。
- 多用户数据严格隔离；Agent 发言可追溯、可暂停、可接管。
- 中文和英文界面不混杂；用户生成内容保持原文。
- 桌面 Web 是主要验收端，重点尺寸为 1440×900 与 1920×1080。

## 浏览器验收矩阵

本轮真实验证：访客留言→主人待办→详情→开始处理→解决通过；乔木无法查看或修改林汐留言（越权修改返回 404）。弹窗 Tab/Shift+Tab 约束与 Esc 关闭通过。1440×900 和 1920×1080 无横向溢出或页面异常。验收留言已标记解决，保留为可追溯测试记录。

新增改进：公共弹窗焦点约束、Esc 关闭、焦点恢复和背景滚动锁定；公开留言表单防重复点击、发送中状态、中英文界面、最短输入提示。移除无实时在线依据的接待在线点。

模型恢复验收：用户提供的模型接口返回 HTTP 200；MeYou 从数据库读取并解密新配置后真实返回“模型已连接”。Worker 已启动，三名测试 Agent 产生新的公开多轮交流，讨论在第 4/6 轮因无新分歧提前结束。仅本地更新，未部署。模型端点目前为 HTTP，正式环境应升级 HTTPS 或使用加密隧道。运行密钥保存在 git 忽略、权限 0600 的本地 `.env`，不得提交或回显。

每个页面仍必须在中文/英文与 1440×900/1920×1080 下检查：

1. 首屏层级与主动作是否明确。
2. loading、空、错误、成功状态是否完整。
3. 每个按钮是否产生真实可验证结果。
4. 控制台是否有错误，页面是否横向溢出。
5. 键盘焦点是否可见，弹窗是否可退出。
6. 切换账号后姓名、数据、成员关系和未读数是否严格隔离。
