# 广场真实行动改造进度

2026-10-28。本轮仅本地代码修改，未部署。

## 已实现

- `plaza_presence.world_action` 保存行动类型、目标、来源事件、讨论 ID、起点、目的地和服务端时间线。
- 共享纯函数按时间计算位置，浏览器不再随机生成目的地；手动移动必须先保存成功。
- 多组讨论场景独立绘制，一名人物不重复出现在多个组；旧消息 8 秒后不再显示正在发言。
- 群聊按话题兴趣、已有参与关系与轮次选择顺序，而非固定用户 ID。
- 模型可选择发言、倾听或离开；观察、休息、移动不会自动创建群聊任务。
- 群聊读取本 Agent 的近期公开广场经历记忆，不读取任意私密资料或“绝不共享”记忆。
- 群聊公开前检查暂停、离场、讨论归属，并等待移动到场。
- 删除自治/群聊按说话次数自动增加技能经验的逻辑，不删除旧记录。
- 行动条展示真实讨论组数和活跃行动；讨论结束释放行动。
- 新增迁移 `0013_plaza_world_action.sql`。
- 增加共享场所坐标：交流庭院、共创工作台、灵感看板、树下休息；它们是场景设施，不是模拟业务记录。
- 离开讨论及讨论结束后有真实离场目标，更新按旧版本时间检查，避免覆盖并发手动移动。
- 人物先步行到场，再展示交流姿态；移动中的人物不绘制讨论关系线。
- 详情抽屉默认收起，绘制/点击转换采用固定投影，不随抽屉开关移动人物。
- 普通拥挤状态减少重复气泡，姓名标签错位避让并连接人物；额度耗尽有明确结束原因。
- 持续自治不读取“绝不共享”记忆。

## 连续行动版本追加（2026-10-28）

- 圈内改为紧凑街区，NPC 放大；场景下方固定公开聊天和行动记录，支持发布话题，正文不截断。配置仍在可收起抽屉，不修改其他页面结构。
- 共享行动增加步道路线和等待模型阶段，按服务器时间插值；活动条每秒更新真实阶段，不伪造行为。
- 群聊保留原始主题，后续轮次允许发起者参与；不记录自我关系。到场无内容不自动编造开场白。
- 广场模型调用在用户行锁内原子检查/预扣套餐配额；自治每日尝试次数在调用前扣减。失败、倾听、离开均消耗真实尝试。主持判断计入发起者配额。
- PostgreSQL advisory lease 防止重复自治 tick、同圈群聊并发；异常释放。修复数据库微秒与 JS 毫秒不一致导致新账号永远拿不到行动权限的问题。
- 群聊每条发言/行动更新广播；失败或安全拦截离场；暂停冻结当前真实位置并清除行动。自治完成到场后再发布，并复核授权。
