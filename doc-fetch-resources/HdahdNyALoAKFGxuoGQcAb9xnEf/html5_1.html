v1.1 升级后劣化（v0.9 同规模稳定一年多）；客户已叫停知识库迁移

master 奇数 3 副本、扩 data 不扩 master（方正今日踩坑）；磁盘 <85%、废弃索引定期清理；先定位 >10s 查询链路
④ 意图识别 30→50 陡降
全量意图进模型 context（3.28s→12.74s），意图数量不可扩展，无法支撑 C 端多场景
→
意图识别属关键路径

→
top-k 意图召回替代全量
向量检索召回 top-k 意图再进 context；意图数量与性能基线绑定，可扩展支撑新场景
