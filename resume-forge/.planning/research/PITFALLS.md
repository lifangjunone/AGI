# Pitfall Research

| Pitfall | Warning | Prevention |
|---------|---------|------------|
| ATS score presented as hiring truth | Users chase 100 instead of relevance | Explain score inputs and avoid outcome guarantees |
| Keyword stuffing | Skills appear without evidence | Label missing terms as evidence gaps |
| AI-created achievements | User cannot defend claims | Generate only from explicit fact fields |
| Decorative export | Text parsing or reading order breaks | Use semantic single-column HTML |
| Hidden download paywall | User loses trust after editing | Keep core export free |
| Resume data leakage | Personal history reaches analytics or model logs | Default to browser-only persistence |
| Shrinking text to force one page | Resume becomes unreadable | Warn on content length instead of dynamic tiny type |
