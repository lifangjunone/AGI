# Stack Research

- React + TypeScript + Vite: fast local-first editor with typed document state.
- Browser localStorage: zero-backend MVP and explicit privacy boundary.
- Semantic HTML export: selectable text and predictable browser print-to-PDF.
- Vitest: deterministic scoring, migration, escaping and export tests.
- Playwright: desktop/mobile workflow, download and overflow verification.

Avoid canvas-based resume rendering because it harms text selection and ATS parsing. Avoid a server-side PDF dependency until exact pagination requires it.
