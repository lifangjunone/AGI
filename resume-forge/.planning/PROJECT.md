# ResumeForge / 简历锻造厂

## What This Is

简历锻造厂是一款面向中文职场人、校招生和转岗者的岗位定向简历工具。用户粘贴目标岗位 JD，录入真实经历与证据，系统实时检查 ATS 关键词、成果量化、表达质量和一页排版，并生成可导出的岗位版本。

## Core Value

让每一条简历描述都有事实依据，并能明确回应目标岗位的招聘要求。

## Business Model

- 免费版：创建 1 份简历、完成基础 ATS 检查并导出 HTML/PDF。
- Pro：目标价 `¥19.90/月`，支持多岗位版本、版本差异、深度改写和高级模板。
- 增长：导出作品页保留弱品牌归因；岗位版本与面试复盘形成持续使用。
- 首版不依赖模型 API，保持零推理成本；后续 AI 只优化已有事实，不创造经历。

### Active

- [ ] 用户可以填写个人信息、职业摘要、技能、教育和多段工作经历。
- [ ] 用户可以粘贴 JD 并看到关键词命中、缺失词和匹配得分。
- [ ] 系统可以检查经历要点中的动作、量化证据、业务影响和长度。
- [ ] 用户可以通过事实字段生成结构清楚的经历要点。
- [ ] 用户可以实时预览一页中文简历，并导出打印友好的 HTML。
- [ ] 草稿仅保存在浏览器本地，刷新后可继续编辑。

### Out of Scope

- 自动伪造经历或数据 - 破坏求职诚信和面试可验证性。
- 自动投递招聘网站 - 风险高且不属于简历质量核心。
- 服务端账号与简历云存储 - 首版优先验证编辑和导出价值。
- 花哨多栏模板市场 - 首版先保证 ATS 可读性和一页信息密度。

## Constraints

- **隐私**: 简历和 JD 默认不离开浏览器。
- **真实性**: 所有建议基于用户提供的事实，不补造数据。
- **兼容**: 支持 1120x720 桌面和 390px 手机。
- **导出**: 使用浏览器打印生成 PDF，保持文本可检索。
- **成本**: MVP 不使用付费模型或后端服务。
