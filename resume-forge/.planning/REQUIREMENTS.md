# Requirements: ResumeForge

**Defined:** 2026-09-15  
**Core Value:** 每一条简历描述都有事实依据，并回应目标岗位要求。

## v1 Requirements

### 基础资料

- [x] **PROFILE-01**: 用户可以编辑姓名、目标岗位、联系方式、城市和职业摘要。
- [x] **PROFILE-02**: 用户可以编辑技能和教育经历。
- [x] **DATA-01**: 草稿自动保存在浏览器，刷新后完整恢复。
- [x] **DATA-02**: 用户可以恢复示例或创建空白简历。

### 岗位匹配

- [x] **JOB-01**: 用户可以粘贴目标岗位 JD。
- [x] **JOB-02**: 系统展示 JD 关键词、已命中词和缺失词。
- [x] **JOB-03**: 系统按内容完整度与关键词覆盖计算可解释匹配分。
- [x] **JOB-04**: 用户点击缺失关键词可定位到相关编辑步骤。

### 经历证据

- [x] **EXP-01**: 用户可以新增、编辑和删除工作经历。
- [x] **EXP-02**: 每段经历支持新增、编辑和删除多个成果要点。
- [x] **EXP-03**: 系统检查每个要点的动作词、量化证据、业务影响和长度。
- [x] **EXP-04**: 用户可以用动作、任务、数字和结果生成一个不虚构的成果要点。

### 预览导出

- [x] **DOC-01**: 编辑时实时生成单栏 A4 简历预览。
- [x] **DOC-02**: 手机端可以在编辑、预览和诊断间切换。
- [x] **DOC-03**: 用户可以导出打印友好的独立 HTML，并通过浏览器打印为 PDF。
- [x] **DOC-04**: 导出内容保持文本可选择和 ATS 可解析。

## v2 Requirements

- **VERSION-01**: 用户可以为多个岗位保存独立版本并比较差异。
- **AI-01**: 用户可以调用 AI 优化已有事实的表达，不得新增事实。
- **ACCOUNT-01**: 用户可以通过 LifeYouMe SSO 跨设备保存加密简历。
- **TRACK-01**: 用户可以记录投递、面试和结果。

## Out of Scope

| Feature | Reason |
|---------|--------|
| 自动投递 | 平台风险高，且不能提升内容真实性 |
| 伪造项目或数据 | 违背产品核心价值 |
| 图片型 PDF | ATS 难以解析，文本不可检索 |
