# 设计说明

## 定位与任务

这是 LifeYouMe 的模型情报子产品。用户首屏的主要任务是：十秒内看懂当前最热模型、厂商、类型和热度依据，再按类型或厂商继续浏览。

## 选定方向

北极星是“编辑部热榜 × 数据终端”：把模型排名当作一份每小时重印的情报版面。沿用 LifeYouMe 的黑白基底和严谨排版，用朱红表示热度，避开 AI 工具常见的紫蓝光晕、漂浮卡片和胶囊按钮。

- 调性：能量中高、完成度精致、密度中高、分量偏重、严肃度偏庄重。
- 首屏骨架：产品名与更新时间只占两行，第一名模型占据主要面积，第二、三名在侧栏；第一屏直接看到榜单内容。
- 字体：系统无衬线负责名称与中文；等宽字体负责排名、热度、时间与数据状态。
- 色彩：纸张灰 `#f2f0e9`、墨黑 `#111411`、热度朱红 `#e64624`。
- 控件：直角、细线、黑底选中态；按下轻微下沉。
- 记忆点：热度条从左向右建立、巨大的模型名与排名数字形成“头版”。

## 交互与动效

1. 首次数据进入时，热度条从零增长。
2. 类型和厂商筛选用固定位置的黑底选中态切换，榜单原地重排。
3. 手动刷新按钮立即进入“刷新中”，完成后用结果型提示交代更新时间。

支持 `prefers-reduced-motion`，减少动态效果时直接呈现最终状态。

## 三个方向留档

探索时比较过三个文字方向：

1. 编辑部热榜：大号排名、纸张底色、朱红热度；信息承载和 LifeYouMe 品牌衔接最好，已选用。
2. 科研观测站：深蓝黑底、轨道图形、荧光绿信号；科技感更强，但容易接近常见 AI 控制台。
3. 模型交易所：高密度表格、跳动行情、红绿涨跌；效率高，但“涨跌”会误导模型能力判断。

## 视觉评审

独立评审 1 轮，初版总分 8/10（桌面 8、移动 7）。保留了巨型中文刊头、朱红排名、前三名编辑编排和开放画布。评审后完成：

- 移动榜单副行由数据源改为“厂商 · 类型”，保留分类上下文。
- 移动筛选与刷新操作扩大到至少 44px 触控高度。
- 第 10 名以后压缩为更紧凑的账簿行，减少长榜无效滚动。
- 移动筛选改为横向排字轨道，避免按钮铺满一整屏。
- 手动刷新增加“刷新中”与“刚刚重印”结果反馈。
- 提升移动端次级说明的字号和对比度。

## UI/UX Pro Max 重设计

2026-10-23 使用 `ui-ux-pro-max` 重新生成并持久化设计系统，源文件位于
`design-system/lifeyoume-model-radar/MASTER.md`。

采用的建议：

- Data-Dense Dashboard：优先保证模型数量、厂商、类型、热度和发布时间的扫描效率。
- 蓝色承担数据与导航语义，琥珀色只强调热点与前三名。
- Fira Code 用于排名、热度和计时，Fira Sans 与中文系统字体负责内容阅读。
- 统一 4/8px 间距节奏、语义色彩 token、可见键盘焦点和至少 44px 的移动触控区域。
- 375、768、1024、1440 四档响应式；榜单保留同一内容结构，不制作互相分叉的移动页面。
- 动效只用于实时状态、雷达扫描、刷新反馈和榜单重排，并支持 `prefers-reduced-motion`。

未采用的建议：

- 自动推荐的 Enterprise Gateway 落地页骨架不符合情报看板任务，因此未使用销售 CTA、客户 Logo 和行业入口。
- 未引入 GSAP；当前原生 CSS 动效已经能表达状态，同时保持零前端依赖和较低运行成本。

## 首屏业务优先级调整

根据产品“统计当下最火模型”的核心目的，首屏从品牌介绍调整为榜单结果优先：

- 第 1 名模型成为首屏面积和字号最大的业务对象。
- 热度、厂商、类型、来源与查看入口均无需滚动即可看到。
- 桌面端同时展示第 2、3 名；移动端先完整交付第 1 名，再自然进入后续排名。
- 产品定位说明退为辅助内容，不再先于榜单结果出现。
- 统计概览继续保留，但放在最热模型之后，避免指标卡抢占核心结果。
