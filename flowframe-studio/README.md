# FlowFrame Studio

一个面向 AI 视频创作的 Web 工作台，覆盖灵感发现、模型接入、视频生成、素材管理、项目管理、时间线编辑和导出反馈等核心体验。

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```

## 已实现

- 文生视频、图生视频和多图参考模式
- 提示词智能扩写、模型/时长/画幅/高级参数配置
- 服务端异步生成任务、供应商状态轮询、完成态和真实任务抽屉
- 灵感广场与“做同款”入口
- 服务端项目创建、搜索、删除与工作空间隔离
- 图片、视频与音频真实上传、持久化、预览和删除
- 完整视频编辑器：媒体区、预览播放器、属性面板、双轨时间线
- 播放游标、片段数、面板选择与画面状态自动保存，刷新后恢复
- 桌面、平板与移动端响应式布局
- 自有模型配置中心，覆盖 5 类核心模型与 5 类增强模型
- 服务端真实连接验证：读取供应商模型目录并精确核对模型 ID
- API Key 仅保存在服务端 0600 数据文件，永不通过读取接口回传浏览器
- 未验证配置只保存为草稿，不会进入创作工作流
- 自定义视频模型验证通过后自动出现在创作页模型选择器

## 产品化接入点

当前视觉样片来自 Unsplash。生成与剪辑区域仍有以下待接入能力：

1. 用 SSE 或 WebSocket 替代当前 3 秒 HTTP 状态轮询。
2. 将本机素材文件迁移为对象存储签名地址，以支持多机扩展。
3. 在导出按钮后接入服务端渲染队列与通知系统；未配置前不会伪造导出成功。

## 模型验证边界

- `OpenAI Compatible`、`Custom API` 与 `本地服务`：请求
  `GET {Base URL}/models`，只有返回列表精确包含配置的模型 ID 才能通过。
- `Replicate`：请求模型详情接口，并核对返回的 `owner/name`。
- 外部供应商必须使用 HTTPS；解析到内网、回环或保留地址时会被拒绝，以避免 SSRF。
- “测试连接”成功后，保存时还会重新验证一次，避免测试后篡改 URL 或模型 ID。
