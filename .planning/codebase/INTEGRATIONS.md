# Integrations And External Services

Inventory date: 2026-08-28. This document records integrations evidenced by
source or deployment configuration. “Optional/configured” means the code path
exists but requires credentials or deployment settings.

## Cross-Project Local Contracts

- `technology-intelligence` writes JSON reports to the macOS Application Support
  directory. `opportunity-factory/app/opportunity_engine.py` reads those files
  from `~/Library/Application Support/Technology Exploration Agent/reports/`.
- `technology-intelligence` exposes a local provider around `127.0.0.1:43128`.
  `delivery-control-center/src/technology-advisory.js` and
  `delivery-pilot/src-tauri/src/technology_advisory.rs` use that provider.
- DeliveryPilot consumes Technology Exploration reports/jobs and a
  `technology-demo-handoff/1.0` file/event inbox under the same Application
  Support area. The handoff implementation is in
  `delivery-pilot/src-tauri/src/lib.rs` and `delivery-pilot/src/App.tsx`.
- LifeYouMe Platform discovers products from
  `lifeyoume-platform/config/products.json` and probes each product's private
  loopback health URL. It does not import product code or databases.
- Debug event posts to local `127.0.0.1:7777` endpoints appear in several
  applications, including `english-speaking-coach/server/index.ts`,
  `english-speaking-coach/src/lib/api.ts`, and `delivery-pilot/src-tauri/src/lib.rs`; these
  are diagnostics rather than product APIs.

## Technology Exploration

- Direct HTTP/JSON/XML sources implemented in
  `technology-intelligence/app/technology_explorer.py` include GitHub Trending
  and GitHub REST repository/search APIs, Hugging Face Models API, Hacker News
  Algolia API, arXiv Atom API, Bilibili API, Google News RSS, YouTube Data API
  v3, X API v2, Telegram public channel pages, NewsNow, Buzzing, 60s API,
  6551 Daily News, AI News, and TikHub.
- API keys/configuration are environment-backed: `YOUTUBE_API_KEY`,
  `GITHUB_TOKEN`, `TIKHUB_BASE_URL`, `ARK_API_KEY`, and `ARK_BASE_URL`.
  Setup and credential guidance is in `technology-intelligence/DATA_SOURCE_SETUP.md`.
- Optional AI reasoning uses an OpenAI-compatible Volcengine Ark endpoint:
  default base URL `https://ark.cn-beijing.volces.com/api/v3`, with chat
  completions in `technology-intelligence/app/technology_explorer.py`.
- Local HTTP provider endpoints are consumed by OneOPC and DeliveryPilot; the
  provider is started by the macOS app wrapper rather than a separately
  declared package.

## Opportunity Compass

- Reads Technology Exploration local report JSON; it does not copy its API keys.
- The autonomous factory calls GitHub REST APIs for issues/repositories,
  Hacker News Firebase API, and OpenSSF Scorecard API. These paths are in
  `opportunity-factory/service/autonomous_factory.py`.
- Publishing integrations include IndexNow
  (`https://api.indexnow.org/indexnow`), PubSubHubbub/WebSub
  (`https://pubsubhubbub.appspot.com/`), RSS, Sitemap, and JSON/Markdown
  public report APIs generated by the factory itself.
- Payments are optional and webhook-gated. Stripe Checkout uses
  `STRIPE_SECRET_KEY`, `STRIPE_PRICE_ID`, and `STRIPE_WEBHOOK_SECRET`; Lemon
  Squeezy uses checkout, variant, and signing configuration. The implementation
  and exact validation are in `opportunity-factory/service/autonomous_factory.py`
  and `opportunity-factory/deploy/opportunity-factory.env.example`.
- Deployment exposes the service through Nginx HTTPS and systemd on local
  port 8787. Relevant files are
  `opportunity-factory/deploy/proxy.conf`,
  `opportunity-factory/deploy/opportunity-factory.service`, and
  `opportunity-factory/deploy/nginx-lifeyoume.conf`.
- The native wrapper uses Cocoa/WebKit, not a remote SaaS integration:
  `opportunity-factory/native/NativeShell.m`.

## LifeYouMe Platform

- Public routing and TLS terminate at Nginx for `lifeyoume.icu`,
  `ops.lifeyoume.icu`, `auth.lifeyoume.icu`, `billing.lifeyoume.icu`,
  `audit.lifeyoume.icu`, and `easysay.lifeyoume.icu`; see
  `lifeyoume-platform/deploy/nginx-platform.conf`.
- Product health checks are HTTP requests to loopback endpoints defined in
  `lifeyoume-platform/config/products.json`.
- Authentication is local signed-cookie session handling and PBKDF2 password
  verification in `lifeyoume-platform/platform/app.py`. OIDC and payment
  services are boundaries/placeholders, not implemented provider SDKs.

## OneOPC

- Electron IPC is the primary integration boundary:
  `delivery-control-center/src/preload.js` exposes a constrained API to
  `delivery-control-center/src/renderer.js`, while `delivery-control-center/src/main.js` owns filesystem,
  process, shell, and external-tool operations.
- Detects local developer tools and may launch Trae Work, WorkBuddy,
  TraeBuddy, Trae Code, Codex, Cursor, Claude Code, GitHub Copilot, and
  related CLI/app binaries. Detection and launch are in
  `delivery-control-center/src/main.js`.
- CodeGraph integration executes a discovered local CLI through
  `delivery-control-center/src/codegraph-adapter.js`; candidate repository validation permits
  GitHub HTTPS URLs.
- Technology advisory starts or talks to a local provider at
  `http://127.0.0.1:43128` and bundles the
  `resources/delivery-computer-use` executable. See
  `delivery-control-center/src/technology-advisory.js`.
- External links are deliberately restricted: local demo outputs must be
  localhost/loopback, and source links are verified GitHub or Hugging Face
  URLs before Electron opens them, as enforced by `delivery-control-center/src/main.js`.
- No cloud database, hosted auth, payment, or direct LLM SDK is integrated.
  Run data and drafts are local JSON files protected with SHA-256.

## DeliveryPilot

- GitHub REST search and repository metadata plus Hacker News Firebase APIs are
  implemented in `delivery-pilot/src-tauri/src/technology.rs`.
- Configurable third-party HTTP technology sources and local Technology
  Exploration sources are handled by
  `delivery-pilot/src-tauri/src/technology_sources.rs`. HTTP source URLs must
  be `http://` or `https://`; API keys are attached as authorization headers
  by the Rust client.
- Requirement recommendations use an OpenAI-compatible Ark endpoint by
  default (`https://ark.cn-beijing.volces.com/api/v3`) in
  `delivery-pilot/src-tauri/src/requirement_recommendation.rs`.
- Technology advisory calls the local Technology Exploration provider at
  `127.0.0.1:43128`, and can launch/focus the local Technology Exploration
  macOS app. See `delivery-pilot/src-tauri/src/technology_advisory.rs`.
- Delivery execution launches local Node/CLI tools and validates local HTTP
  demo servers through loopback URLs in
  `delivery-pilot/src-tauri/src/delivery_runtime.rs`.
- The Swift sidecar is a local macOS Computer Use bridge. It uses Accessibility
  permission, AXUIElement inspection, CoreGraphics mouse/keyboard events, and
  system preference URLs in
  `delivery-pilot/sidecars/macos-computer-use/Sources/DeliveryComputerUseV2/main.swift`.
- Persistent local storage is bundled SQLite via `rusqlite`; schema/migrations
  are in `delivery-pilot/src-tauri/migrations/001_initial.sql`. Tauri IPC and
  events connect the React UI to Rust.

## EasySay

- Node API runs on port 8787 by default and serves the React/PWA frontend,
  health/status endpoints, learning APIs, and speech routes from
  `english-speaking-coach/server/index.ts`.
- Ark integration uses the OpenAI-compatible SDK and
  `ARK_BASE_URL`/`ARK_API_KEY`; reasoning, vision, and image model settings
  are implemented in `english-speaking-coach/server/ark.ts` and
  `english-speaking-coach/server/hermesConfig.ts`. The frontend never receives the API key.
- Local speech gateway calls `http://127.0.0.1:8790/v1/asr` and `/v1/tts`;
  Node routing is in `english-speaking-coach/server/speech.ts`, and the Python FastAPI/MLX
  implementation is in `english-speaking-coach/speech/service.py`.
- Browser fallback uses Web Speech Recognition and `window.speechSynthesis`
  in `english-speaking-coach/src/hooks/useSpeechRecorder.ts` and `english-speaking-coach/src/lib/speech.ts`.
- Optional Hermes Agent integration launches a local Hermes process and can
  target a local OpenAI-compatible Qwen3.5 MLX service at `127.0.0.1:8800/v1`;
  see `english-speaking-coach/server/hermes.ts` and `english-speaking-coach/config/local-llm.json`.
- Capacitor native clients use a Mac gateway URL and six-digit access code,
  configured through `english-speaking-coach/server/mobileBootstrap.ts`,
  `english-speaking-coach/server/mobileAuth.ts`, and `english-speaking-coach/src/lib/nativeConnection.ts`.
- Product data is local IndexedDB and local model files. There is no remote
  application database, analytics SDK, or hosted authentication provider.

## Foundation, FDE Fieldbook, And Nexora

- `english-foundation/`, `fde-playbook/`, and `agent-workforce-console/` are local/browser
  applications with no implemented backend, database, authentication,
  payment, or third-party API client.
- `fde-playbook/src/styles.css` references Google Fonts and a prescribed
  `copilot-cn.bytedance.net` text-to-image endpoint; these are browser asset
  dependencies, not application data APIs.
- `delivery-pilot/src/stores/workforceStore.ts` also references the same
  text-to-image endpoint for generated workforce avatars.
