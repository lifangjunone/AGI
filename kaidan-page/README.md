# 开单页 Kaidan

把一项技能在 10 分钟内包装成可报价、可分享、可导出的服务售卖页。

## 当前可用

- 从简历诊断、视觉设计、AI 自动化三个模板开始，或创建空白服务。
- 编辑目标客户、结果承诺、可信依据、交付内容、周期和月度产能。
- 配置体验、主推、高阶三档价格，获得价格梯度提示，并在买家预览中切换方案。
- 配置微信、邮箱或电话及行动按钮，联系方式会进入预览和导出售卖页。
- 测算月营收、免费版 3% 平台费、Pro ¥29/月和产能风险。
- 自动保存浏览器草稿并显示保存时间，复制首发文案，导出可独立打开的 HTML 售卖页。
- 手机端默认进入编辑，可在编辑/预览间切换；发布缺项可定位，清空草稿前需确认。

当前版本是本地优先 MVP。没有真实公网发布、买家支付、订单或收入数据，不会将预估值表述为真实成交。

## 运行

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:5173`。生产构建：

```bash
npm run build
npm test
npm run test:e2e
```

## 商业模型

- 免费：发布 1 个服务，未来真实成交后收取 3% 平台费。
- Pro：¥29/月，多服务、移除品牌标识、免平台抽成。
- 增长：免费售卖页保留“用开单页创建”入口，用户分享自己的服务时同步带来新用户。

## 数据边界

- 草稿仅写入浏览器 `localStorage`。
- 导出操作在浏览器本地完成。
- 当前没有账号、服务端数据库、支付或分析追踪。
