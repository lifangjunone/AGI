# Roadmap: 开单页

## Phase 1: 可分享的开单 MVP
**Goal:** 用户能在一次会话内完成服务商品化、利润测算并导出售卖页。  
**Mode:** mvp

**Requirements:** OFFER-01..04, PAGE-01..04, MONEY-01..03, GROW-01..02, DATA-01..02

**Success Criteria:**
1. 新用户从模板进入后 10 分钟内可获得完整售卖页。
2. 390px 和 1120x720 视口无关键控件遮挡或横向溢出。
3. 导出的 HTML 可独立打开，且不依赖应用运行。
4. 刷新页面后草稿完整恢复。
5. 单元测试、生产构建和浏览器核心流程全部通过。

## Phase 2: 真实发布与线索
**Goal:** 每个用户获得公网链接，并能收集真实购买意向。
**Mode:** mvp

**Success Criteria:**
1. 售卖页可通过稳定 URL 公开访问。
2. 买家可提交经过同意的联系方式和购买意向。
3. 卖家能看到来源、访问和转化数据。

## Phase 3: 收款与履约
**Goal:** 打通真实支付、订单状态和交付确认。
**Mode:** mvp

**Success Criteria:**
1. 至少一笔真实小额订单完成支付、回调和履约。
2. 订单金额、平台费和卖家收入可审计。
3. 退款与失败状态不会被展示为收入。

## Phase 4: 增长网络
**Goal:** 用模板、分销和复购形成可规模化增长。
**Mode:** mvp

**Success Criteria:**
1. 免费页面归因可统计新增卖家。
2. 分销佣金只在真实履约后确认。
3. 模板市场产生首笔真实交易。
