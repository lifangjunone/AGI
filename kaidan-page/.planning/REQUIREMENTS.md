# Requirements: 开单页

**Defined:** 2026-09-14  
**Core Value:** 让用户完成一张敢于发出去的服务售卖页。

## v1 Requirements

### 商品化

- [x] **OFFER-01**: 用户可以选择空白、高频模板并立即获得可编辑内容。
- [x] **OFFER-02**: 用户可以编辑服务名称、目标客户、结果承诺、交付内容、周期与名额。
- [x] **OFFER-03**: 用户可以配置体验、主推、高阶三档报价。
- [x] **OFFER-04**: 系统根据完整度给出发布准备度和明确缺项。

### 售卖页

- [x] **PAGE-01**: 用户编辑时可实时预览手机端售卖页。
- [x] **PAGE-02**: 售卖页清楚展示适用人群、交付结果、套餐和行动按钮。
- [x] **PAGE-03**: 用户可以将完整售卖页导出为独立 HTML 文件。
- [x] **PAGE-04**: 免费导出页包含“用开单页创建”归因入口。

### 经营测算

- [x] **MONEY-01**: 用户可以看到不同月销量下的收入、平台费和预计到手金额。
- [x] **MONEY-02**: 系统根据交付时长和月度产能提示不可兑现的销量目标。
- [x] **MONEY-03**: 用户可以比较免费抽成与 Pro 订阅的盈亏平衡点。

### 增长行动

- [x] **GROW-01**: 用户可以一键复制针对私域发布的首发文案。
- [x] **GROW-02**: 系统提供三个可在当天完成的首单动作。
- [x] **DATA-01**: 草稿自动保存在当前浏览器，刷新后继续编辑。
- [x] **DATA-02**: 用户可以恢复示例或清空为新服务。

## v2 Requirements

### 交易

- **PAY-01**: 买家可在售卖页完成微信或支付宝支付。
- **ORDER-01**: 卖家可查看订单、交付状态和退款状态。

### 增长

- **AFF-01**: 用户可创建分销链接并自动结算佣金。
- **DOMAIN-01**: Pro 用户可绑定自定义域名。
- **AI-01**: 用户可选用 AI 优化服务定位与销售文案。

## Out of Scope

| Feature | Reason |
|---------|--------|
| 社交内容社区 | 增加审核和冷启动成本，不直接提升首单率 |
| 复杂拖拽建站 | 容易让用户陷入装修，延迟发布 |
| 虚构订单或收入 | 破坏信任，所有经营数据必须由用户输入或真实交易产生 |
