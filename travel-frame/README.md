# 旅帧 TravelFrame

一个面向旅行照片的本地优先智能整理产品原型：按时间、地点、景色、人和动作自动归类，并从连拍与相似照片中推荐最佳画面。

## 运行

```bash
npm install
npm run dev
```

在浏览器访问终端给出的地址。点击「导入照片」可以导入本地图片进行预览；本原型不会上传文件。

## 已实现的产品体验

- 首页的「今天为你整理」任务卡：先呈现旅行精选、相似照片、待确认照片，降低整理压力
- 类 App 的底部五栏导航：首页、智能整理、旅行地图、相册、我的
- 「智能整理」页：按景色类型筛选、AI 精选数量、质量分、人工一键加/移精选
- 每一项智能结论强调用户最终决定权，并明确分析结果只保存在本机
- 面向手机优先设计；窄屏下为双列相片流与可横滑任务卡

## 中文产品 UX 原则

1. **先给结论，再给工具**：用户打开的是“今天该处理什么”，不是一堆算法标签。
2. **推荐可解释、可撤销**：精选结果有质量依据，点一下就能加入或移出。
3. **少配置、多默认**：以自动旅行、自动地点、自动精选收敛操作，不要求用户先创建相册。
4. **本地照片，先讲清隐私**：醒目说明照片分析和结果的保存范围，云同步需另行授权。

## 调研输入与产品映射

| 产品 | 借鉴能力 | 在旅帧中的落点 |
| --- | --- | --- |
| Google Photos | Photo Stacks、自然语言 Ask Photos、自动挑选代表照片 | 相似/连拍分组、意图搜索、每组封面候选 |
| Apple Photos | 人物、地点、日期、回忆及端侧分析 | 旅行叙事、人物聚类、隐私优先的本地分析 |
| 腾讯相册管家 / 百度一刻相册 | 清理相似图、分类入口和云端相册 | 首页“今天为你整理”、一键处理任务卡、低学习成本的中文文案 |
| Immich | 可自托管的人脸聚类、元数据与语义搜索 | 可选私有部署、向量索引与明确的 AI 开关 |
| Aftershoot | 模糊、闭眼、曝光异常和重复帧检测 | 质量评分、废片筛除、保留人工最终决定 |

## 下一步技术实现

1. 读取 EXIF（拍摄时间/GPS/设备）；使用反向地理编码生成地点。
2. 使用本地模型做人物检测、人脸聚类、场景/动作标签、OCR 与图像向量。
3. 将质量评分拆解为清晰度、曝光、构图、表情、重复度；始终展示原因和同组照片。
4. 以 SQLite + 向量索引保存元数据；采用任务队列增量分析，避免导入时卡顿。
