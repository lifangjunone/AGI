# Skill Radar 设计说明

## 目标

用户来这里不是理解“Skill 是什么”，而是快速回答两个问题：今天哪些 Skill 值得看；我关心的领域有哪些成熟选择。

## 三个首屏方向

1. **编辑部榜单**：奶白纸面、超大排名数字、红色校准线，像一份每日出版的工具情报。内容承载强，但容易接近资讯杂志。
2. **雷达仪器**：墨黑底、荧光绿坐标与密集数据，领域分布成为主视觉。识别度强，但中文长时间阅读负担偏高。
3. **研究台账（选定）**：冷灰画布、钴蓝索引、横向证据条。首屏直接给出第一排 Skill 和可解释指标，既像研究索引，又保持日常工具的阅读效率。

## 选定方向

- 北极星：像一份每天更新的 AI 技能雷达，而不是又一个模板市场。
- 品类：内容目录 / 工具发现。参考 `skills.sh` 的内容优先和可安装信息，但不复刻其暗色终端语法；参考 GitHub Trending 的证据密度，但用领域导航替代语言导航。
- 调性：能量偏安静、完成度精致、密度中高、分量中等、严肃度偏研究工具。
- 首屏：两行内页头与搜索，接领域索引和完整第一排条目；不放占据首屏的营销口号。
- 字体：中文系统黑体；数字与安装命令使用等宽字体。
- 色彩：`#F3F5F2` 底色、`#10233F` 主文字、`#2357D8` 主操作、`#D7FF45` 今日增长提示。
- 控件：4px 小圆角、1px 冷灰描边、按下位移 1px；选中项使用移动底板。
- 动效：像索引卡被磁扣“咔嗒”吸合。首次进入按阅读顺序出现；筛选底板滑动；复制命令后按钮文字与状态原地改变。
- 记忆点：每张 Skill 的证据条把安装量、趋势与可信度画成可比较的长度，而不是只摆数字。
- 放弃：紫蓝光晕、巨幅口号、满屏彩色标签、卡片套卡片和不可解释的“AI 推荐分”。

## 关键状态

- 加载：保留列表骨架，不闪白屏。
- 正常：热门 / 增长 / 官方三种排序，领域、兼容 Agent 与关键词可组合筛选。
- 空结果：保留当前筛选并提供一键清除。
- 数据陈旧：顶部明确显示最后成功更新时间，不伪装实时。

## 设备与验收

- 桌面 1440×900、手机 390×844。
- 中文标题与说明不裁切，键盘可完成筛选和复制。
- `prefers-reduced-motion` 下所有内容直接到位。
