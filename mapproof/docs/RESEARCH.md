# MapProof 商机调研

调研日期：2026-11-02（Asia/Shanghai）

## 原始信号

X 帖子介绍开源项目 Diagram Design：让 Claude Code、Codex、Cursor 通过自然语言
生成 45 类专业图表，支持品牌配色、Mermaid/draw.io 导入与 HTML + SVG 导出。
帖子公开数据为 7,280 次浏览、108 个赞、92 次收藏、14 次转发与 8 条回复。

公开可见评论出现了两个比“好用”更值得产品化的信号：

- “重排 Mermaid 时先保住箭头方向、条件和分组关系”，说明用户担心美化时破坏语义；
- “节点一多，连线还能保持清楚吗？”，说明复杂图的可读性没有被生成能力解决。

原项目 README 也明确承认：输出质量依赖模型、同一提示可能产生不同布局、产物
不是适合 Git diff 的可编辑源格式；持续变化的工程文档仍更适合 Mermaid。

## 机会判断

不复制“AI 生成图”，而是占据它的下游：**图表发布验收**。

目标用户：

- 需要提交架构方案、投标书、POC 报告的解决方案架构师和售前；
- 需要在评审中解释系统边界、故障路径与依赖关系的研发负责人；
- 使用 AI 批量生成技术文档，但缺少统一质量门禁的团队。

核心工作：

1. 粘贴 Mermaid 或 AI 生成图；
2. 检查箭头、分支条件、孤立节点、循环、枢纽密度和认知负荷；
3. 提取关键路径并给出可发布 / 需复核 / 暂缓发布结论；
4. 导出带源图和审稿意见的验收报告。

## 为什么能收费

主流工具已经验证了“图表协作”付费意愿：Mermaid Chart 提供每用户每月 10 / 20
美元档位，Eraser Business 公示 45 美元/月档位。MapProof 不以更多图形模板竞争，
而以“降低错误进入客户材料和评审会的概率”定价。

建议商业路径：

- Free：浏览器本地验图、基础规则、Markdown 报告；
- Pro（¥39/月）：自定义品牌规则、更多图型、历史基线对比；
- Team（¥129/人/月）：CI 门禁、规则共享、审批留痕、私有部署；
- 服务包：面向投标/POC 的架构材料体检，按次收费。

## 首版边界

- 仅支持 Mermaid flowchart / graph 的规则检查；
- 不保存用户输入，不调用大模型；
- 规则结论不能替代领域专家的业务语义确认；
- 后续优先验证用户是否愿意为“团队规则 + CI 门禁”付费，而不是先扩充图表类型。
