# 邻店增长：低成本本地商家内容服务

这是一个“先服务、后软件化”的现金流项目。它不承诺自动赚钱，也不依赖先积累平台流量；目标是用可直接演示和交付的工具，向附近的小商家销售一个边界清楚的小结果。

## 为什么选这个方向

### 选择标准

| 方向 | 启动资金 | 首次收款路径 | 平台依赖 | 交付可控 | 结论 |
| --- | ---: | --- | --- | --- | --- |
| 囤货电商 | 高 | 选品→进货→投流→成交 | 高 | 中 | 不选 |
| 自媒体流量号 | 低 | 持续创作→涨粉→变现 | 很高 | 低 | 不选 |
| 通用 AI SaaS | 中 | 开发→获客→订阅 | 高 | 中 | 不选 |
| 本地商家产品化服务 | 很低 | 找店→样稿→收定金→交付 | 低 | 高 | **选择** |

这个方向的优势不是“市场没人做”，而是：

1. 顾客就在附近，可以零广告费触达；
2. 先卖 99 元小结果，比直接卖数千元代运营更容易验证；
3. 内容可以由工具起草、人工校对，早期无需 API 和服务器成本；
4. 收款与交付链路短，最差情况下也能人工完成；
5. 做过 5–10 单后，才有资格根据重复需求继续软件化。

## 调研结论与证据强度

调研日期：2026-09-30。

公开搜索能确认：

- 抖音官方已有创作者中心、DOU+ 和抖店等经营工具，说明商家内容、推广、转化已形成完整生态；
- 国家统计局 2025 年国民经济和社会发展统计公报可作为消费和服务业宏观背景材料；
- 搜索中存在大量“本地商家短视频代运营”“小红书代运营”“大众点评回复代运营”的服务页面与报价内容，证明供需类别存在，但搜索结果质量参差，不能把营销文章里的价格当作可靠成交价。

因此，本项目没有虚构“市场均价”，而是把 ¥99 / ¥399 / ¥1,299 作为三档**验证报价**。最可信的证据将来自你自己的 50 次有效触达：

- 回复率；
- 愿意看样稿的比例；
- 付款率；
- 单次交付用时；
- 复购或升级率。

若 50 次精准触达后仍无人愿意支付 99 元，应该换行业、改交付结果或停止，而不是继续堆功能。

## 收费产品

### 99 元体验包

- 门店线上内容诊断 1 份
- 3 条短视频口播脚本
- 10 条好评/差评回复
- 24 小时交付，修改 1 次

建议先收 50% 定金。它是低门槛验证品，不应无限修改。

### 399 元标准包

- 7 天内容发布日历
- 10 条完整短视频脚本
- 20 条评价回复
- 团购卖点与主页介绍

### 1,299 元月度陪跑

- 每周内容计划与复盘
- 30 条脚本
- 评价回复维护
- 每月一次到店拍摄指导

不要承诺播放量、到店量或收入；只承诺清单内可验收的交付物。

## 运行

要求 Node.js 18 或更高版本，无需安装依赖：

```bash
cd /Users/bytedance/Desktop/agi/local-growth-cashflow
npm start
```

打开 <http://127.0.0.1:4173>。

工具包含：

- 可编辑商家信息；
- 服务端 AI 生成诊断、脚本、评价回复和 7 天计划；
- 火山方舟主通道、授权兜底通道和自动故障切换；
- 快速、品质、深度三档生成模式；
- 模型健康检查、耗时与 token 用量展示；
- 一键复制三档销售话术；
- 本地客户线索漏斗；
- CSV 导出；
- 密钥仅保存在被 Git 忽略的 `.env`，不会下发到浏览器；
- 无服务器数据库；输入会发送给所选模型服务进行生成，请勿填写个人敏感信息。

### 模型配置状态

项目会从 `.env` 读取模型配置，浏览器只能访问脱敏后的模型名称和健康状态。

火山方舟的 OpenAI 兼容入口为 `https://ark.cn-beijing.volces.com/api/v3`。方舟聊天接口实际调用时通常需要在控制台创建并授权一个推理接入点，模型参数形如 `ep-xxxxxxxx`；仅出现在 `/models` 目录中的基础模型名称，不代表当前 API Key 已经拥有推理权限。

当前配置保留方舟作为主通道，并在它不可用时自动切换到兜底通道。要启用方舟，请在控制台创建可用 Endpoint 后，将 `.env` 中三个 `ARK_*_MODEL` 更新为对应的 `ep-...`：

```env
ARK_ENABLED=true
ARK_PRIMARY_MODEL=ep-your-quality-endpoint
ARK_FAST_MODEL=ep-your-fast-endpoint
ARK_REASONING_MODEL=ep-your-reasoning-endpoint
```

如果只有一个 Endpoint，三个字段可以填写同一个 ID。修改后重启服务，再在页面点击“重新检测”。

## 首单执行 SOP

### 第 1 天：只选一个行业

首选附近门店密集、老板在店、消费频次不太低的行业。餐饮、美业、健身、宠物均可，但第一周只选一个。

在地图、点评平台或线下步行中找 20 家：

- 近期仍营业；
- 产品有特点；
- 线上内容弱或长期没更新；
- 能找到老板/店长；
- 不碰医疗、金融等高风险行业。

只记录公开业务信息，不抓取或滥用个人资料。

### 第 2 天：做 3 份样稿

用工作台输入店名、产品、客群和明显问题。生成后必须人工检查：

- 事实是否准确；
- 有没有不实承诺；
- 是否具体到这家店；
- 是否像真人会说的话；
- 是否包含一个清晰行动指令。

样稿只展示诊断的一部分和 1 条脚本，完整内容付费后交付。

### 第 3–4 天：完成 20 次有效触达

当面开场：

> 老板你好，我住/工作在附近。看了你们线上内容，我顺手做了一小段针对店里的脚本，不是让你现在买代运营。你给我 30 秒看一下，如果完全没用我就不打扰。

对方认可后：

> 我现在做一个 99 元体验包：1 份诊断、3 条脚本和 10 条评价回复，24 小时交付，含 1 次修改。你可以先用，不合适就不续。我不承诺播放量，只保证交付内容。

私信版本可直接在网页报价卡中复制。不要群发完全相同的话术；必须说明为何选中这家店。

### 第 5 天：收定金与交付

付款前用文字确认：

> 本次为 99 元体验包，包含诊断 1 份、短视频脚本 3 条、评价回复 10 条；24 小时内交付，含 1 次文字修改。不包含拍摄、剪辑、账号代发，不承诺播放量或成交量。确认后先付 50%。

交付后收尾：

> 你先选一条最愿意拍的。我可以免费帮你把这一条再改得更像老板本人说话；如果这一周确实有用，再考虑 399 元标准包。

### 第 6–7 天：复盘

记录：

- 目标门店数；
- 找到老板/店长的人数；
- 看样稿人数；
- 报价人数；
- 付款人数与收入；
- 每份交付耗时；
- 拒绝原因原话。

## 7 天止损与迭代规则

- 触达少于 20 家：数据无效，继续执行，不能怪产品；
- 20 家中少于 3 家愿看样稿：样稿不具体或开场太像推销；
- 有人看、无人付款：交付价值或报价不清楚，先改变结果描述；
- 有 1–2 单但交付超过 3 小时：缩小范围或提高价格；
- 50 家精准触达仍为 0 单：停止当前行业，保留工具，换相邻行业重新验证；
- 体验包成交 3 单以上：开始测试 199 元，而不是立刻开发复杂 SaaS；
- 5 单中 2 单愿升级：再考虑加入 AI API、自动排版和客户门户。

## 成本和收入模型

初始现金成本可以为 0：

- 本地运行工具：0 元；
- 获客：步行/地图/公开店铺页，0 元；
- 交付：文本或 PDF，0 元；
- 可选打印样稿、交通：控制在 50 元内。

示例而非承诺：

| 月成交结构 | 收入 |
| --- | ---: |
| 5 个体验包 | ¥495 |
| 3 个标准包 | ¥1,197 |
| 1 个月度包 | ¥1,299 |
| 合计 | ¥2,991 |

收入是否成立，取决于真实触达和续费，不能由软件本身保证。

## 合规和信誉边界

- 不刷评、不买量、不伪造顾客案例；
- 不复制竞争对手文案；
- 不公开顾客个人信息；
- 不使用未经许可的照片、音乐或字体；
- 不替客户发布未经确认的内容；
- 医疗、金融、减肥功效等高风险行业不作为初期客户；
- 所有 AI/模板内容在交付前人工核实；
- 依法处理收款、合同与税务问题。
