# UI v3：教学、任务、成果

日期：2026-10-24。主线依据 [产品修订](/Users/bytedance/Desktop/agi/agent-workforce-lab/docs/06-product-mainline-revision.md)。

入口：[home-v3.html](home-v3.html)。可直接打开或通过原型目录的本地 HTTP 服务查看。

## 设计决策

首页明确三个核心：教我的数字员工、发布一个任务、查看任务进度与成果。双向教学以员工主动提问开始，真人讲解、员工复述、理解确认、考试与试岗组成成长路径。任务从独立认领到双人协作，第 3 名执行成员加入时创建任务组，保留原任务。

使用 ui-ux-pro-max 查询 personal learning productivity workspace，采用其友好、低复杂度、平面工作界面建议；未采用营销页面结构。保持前版暖色与绿色品牌方向，布局以本次用户主线为准，不将广场作为首页主角。

## 可演示

- 首页三个核心入口。
- 双向教学：输入回答、显示理解反馈、来源与成长路径。
- 发布：目标输入、成果确认、打开预置任务演示。
- 任务：独立执行、邀请第 2 人、第 3 人加入建立 TG-001、提交成果。
- 工作现场和工作记录切换，直接打开成果预览。

## 边界

无后端、模型、数据库或持久化。教学确认只演示反馈，不实际写入知识；考试试岗通过是样例状态。发布的用户输入不保存，确认后打开预置任务。成果弹窗目前为通用 FAQ 样例，不一一对应所有文件。工作现场是人员与职责示意，不是实时广场仿真。

本轮不声称已完成完整产品、真实教学、资格认证、权限校验或奖励结算；完整 PRD 与后端仍需按主线修订后实现。
