# v4 数字校园：实际演化记录

2026-10-24。范围仅为静态交互原型，旧版保持不动。

每轮都在前一轮产品基础上完成「渲染前图 → 查看问题 → 修改 → 渲染后图 → 视觉复查」。截图由 `review.cjs` 产生，逐轮 before/after 均已打开检查；第 10 轮另外检查四个尺寸。不是十套换色模板，也不是十条检查项。

## 逐轮证据

截图路径相对于本文件。每行的结论是本次设计者复查，不等于客户用户测试。

| 轮次 | 当前截图 / 修改后截图 | 具体问题 | 实际修改 | 复查与保留结论 |
|---|---|---|---|---|
| 01 首屏构图 | [前](evidence/round-01/before.png) / [后](evidence/round-01/after.png) | 创建介绍与地图过高，三入口落到折叠线以下 | 缩短空态和标题留白，调整地图比例，增大快捷入口文字 | 1440 首屏三入口出现；保留校园与操作面板双栏 |
| 02 空间操作 | [前](evidence/round-02/before.png) / [后](evidence/round-02/after.png) | 建筑选中只是标题变色，与操作面板关系弱 | 增加「正在这里」指示、建筑底部投影、面板顶边与按钮 hover | 空间、文字入口和面板的选中状态一致，不需要精确点建筑 |
| 03 员工身份 | [前](evidence/round-03/before.png) / [后](evidence/round-03/after.png) | 教学头像与地图人物不是同一表现，地图人物偏小 | 使用同一个原创 SVG 人物；放大肖像，阶段状态关联员工 | 晓禾从地图到面板可识别，笔记本道具保持一致 |
| 04 双向教学 | [前](evidence/round-04/before.png) / [后](evidence/round-04/after.png) | 看起来只是普通文本提交，没表现「它主动问」 | 强化请教框，展示示范→复述→确认的小流程；教学草稿跨空间保留 | 请教与教学输入在一屏，回答能进入下一步；未声称真实模型提问 |
| 05 知识沉淀 | [前](evidence/round-05/before.png) / [后](evidence/round-05/after.png) | 原文、反馈、表单层层堆叠；记录来源状态不明显 | 原文可展开，方法卡 K-001 可编辑，方法/条件/来源/待确认分开 | 面板压缩且来源可回看，确认动作独立于资格获取 |
| 06 考试试岗 | [前](evidence/round-06/before.png) / [后](evidence/round-06/after.png) | 勾一个框就通过，缺少错误选择与证据转折 | 场景选择题、越权答案失败与重试；试岗产物和资格范围分开 | 错误处理不通过，考试不等于试岗；保留人工模拟检查标注 |
| 07 发布与自评 | [前](evidence/round-07/before.png) / [后](evidence/round-07/after.png) | 表单结束后看不出员工如何接单，时间字段无业务提示 | 发布页增加接单判断预告；独立执行页区分能做/还缺/决定；过去时间报错 | 用户目标和成果保留，资格不足等待；固定判断明确为样例 |
| 08 中途拉人 | [前](evidence/round-08/before.png) / [后](evidence/round-08/after.png) | 三人站广场但像换人数；项目室只是小文字牌 | 独立/双人工位，第三人建立带桌面的项目室，1→2→3阶段条、原任务编号和成员分工 | 第三人才建组，已有任务和记录不重建；三人角色道具不同 |
| 09 成果反馈 | [前](evidence/round-09/before.png) / [后](evidence/round-09/after.png) | 长记录挤占成果；退回立即假装修订完成；没有评审门槛 | 折叠完整文字记录，三成果不同内容；退回→待修订→新版本→重新评审→真人验收；经验候选待确认 | 成果按钮各开自己的内容，评审前不能验收，反馈不会直接变成事实 |
| 10 响应式精修 | [前](evidence/round-10/before.png) / [后](evidence/round-10/after.png) | 375 和 1024 没横向滚动却内部裁切建筑；小屏角色过大 | 显式画布宽高，响应式缩角色/项目室；正常字号面板、触控目标、对比与来源查看 | 四尺寸建筑完整；保留小屏概览，不缩小业务表单 |
| 11 额外交互回归 | [前](evidence/round-11/before.png) / [后](evidence/round-11/after.png) | 小屏切换后还须寻找面板；新增教学会丢上一条记录；产物归属弱 | 切换空间定位面板与焦点；历史方法保留；成果显示作者/来源/版本；阻止覆盖已有任务 | 业务连贯性增强，单任务范围明确；完整故事另由 verify.cjs 回归 |

## 没有被这些轮次证明的事

没有真实客户访谈、盲测、可用性量化测试；因此不能声称已证明所有客户能理解。下一评审建议让未看方案的人完成「教学、发布、看成果」三个动作，观察能否解释第三人为什么建组。

本原型没有模型、Semantica、资料解析、真实权限、持久化或后台调度。最终评审通过后才进入业务编码阶段。
