# Workforce Campus v4 设计系统与交互规范

## 产品主线与首页

真人持续教学 → 理解确认 → 场景考试 → 简单任务试岗 → 发布目标 → 独立认领 → 中途邀请 → 第三位执行成员建立任务组 → 成果、修订、独立评审、真人验收 → 经验回流。

不是员工管理后台，也不是观赏小镇。首页校园直接连到三个工作空间：教学室、任务发布台、交付大厅。建筑、下沿文字按钮、右侧操作面板共享一个选中状态。操作不等待人物动画。

## ui-ux-pro-max 使用与取舍

运行产品级 `--design-system` 查询 `spatial learning workspace`；返回沉浸式体验 / VisionOS 风格，和本产品的空间交互部分匹配，但其 VR、玻璃面板、灰色方案不适合此处。没有把这一结果当作已验证的等距校园模板。

采用：空间连续性、可见选中状态、清晰触控目标、表单标签、键盘焦点、减少动效、反馈与错误可发现。

不采用：VR/AR 前提、透明玻璃叠层、只有地图图标没有文字入口、把运营指标作为首页主视觉、复杂粒子或行走动画。

追加 `error summary validation --domain ux`：采用字段旁 `role=alert` 与 `aria-describedby`、失败定位字段，不用 toast 替代错误。多字段目前借助原生 required 校验；尚未加入自定义多错误摘要。

查询已选后续 React 技术栈 `form state accessibility --stack react`：保留可见标签与独立本地状态的原则。当前设计原型采用原生 HTML/CSS/JS，未提前实现 React 业务应用；后续迁移应拆为 CampusScene / TeachingWorkspace / TaskComposer / DeliveryWorkspace / DomainFlow。

## 视觉语言

- 暖纸与鼠尾草校园，墨绿动作；金色发布空间、陶土色交付空间、淡紫项目室。
- 主色 `#365c47`；正文 `#293e37`；次级 `#637267`；纸面 `#fffdf7`；底色 `#f3f3ec`；错误 `#a74031`。
- 中文系统字体栈，不下载字体；主标题 27px，面板标题 23px，输入 14px / 手机 16px。次要地图概览文字可以更小，但完整业务信息在正常字号面板中。
- 页面间距以 8px 为主，面板 20–24px，圆角 8/12/16/20px；仅地图建筑使用轻投影。
- 建筑与人物均为原创可编辑 SVG。晓禾携笔记本、知远展开分类地图、青岚戴眼镜并持核对卡；不只靠服装颜色区分。
- 不使用 emoji 作为结构性图标，不复制竞品角色或图片。

## 布局与响应式

1440：校园 / 当前空间双栏；1024：保持双栏，地图固定可控高度；≤850：地图概览在上、业务面板在下；375：三个建筑和文字入口保留，人物缩小，输入不缩小。

禁止用 `overflow:hidden` 作为地图撑宽的修复。地图明确 `width:100%`、小屏取消宽高比推导，四尺寸同时检查建筑边界。切换空间后，小屏定位完整操作面板，桌面不强制滚动。

## 连续身份、教学与资格

同一晓禾贯穿故事。教学输入形成来源原文；可编辑方法与条件必须由教学者确认。确认不是通过考试。

考试用固定示例选择题展示成功与失败；试岗以具体样例产物独立核查。都是 UI 演示者模拟操作，不是实际 Agent 作答或能力认证。新知识另行学习与验证，上一条来源方法可回看。

## 任务与动态协作

任务目标、产物要求与时间保留用户输入。发布前确认处理权；资格不足等待，不出现执行成员。

合格故事：晓禾独立开始 → 发现分类缺口邀请知远 → 例外核对邀请青岚 → 第三人建立 TG-001。校园工位与项目室随人数变化，原任务编号不变。加入说明包含职责与理由，评审角色不计为第四个执行成员。

匹配理由是固定示例，不是针对任意目标的真实推理。原型限制一项任务；已有任务不被再次发布覆盖。

## 成果、反馈与验收

三份产物对应目标分析、工作方案、风险事项，内容分别打开，包含原任务、教学方法、适用条件与负责人。

退回反馈先进入「正在修订」，保留旧版本；完成样例修订后增加版本，再独立评审，再真人验收。未评审禁用验收，接受后退回禁用。重复验收只查看记录，不再展示第二次发奖。100 积分是不可兑现的样例展示，无真实账本。

经验回到教学室作为候选，须确认，不自动成为事实或 HR 绩效。

## 动效与可访问性

动作反馈 160–200ms，角色位置 700ms，仅表达成员加入与空间变化。所有操作可立即点击，支持跳过交付、手动暂停与 `prefers-reduced-motion`。

原生按钮/表单/对话框；键盘焦点可见，Tab 跳到主面板，Escape 关闭弹窗，返回仍存在的触发控件。没有拖拽必需动作、自动播放或外部命令执行。

完整文字工作记录是地图的替代，不要求仅凭色彩或动画识别。

## 竞品引用边界

- [Lindy Watch and Learn](https://www.lindy.ai/product/watch-and-learn)：借鉴示范→澄清→执行；不声称本原型有其实际学习功能。
- [Sintra](https://sintra.ai/)：借鉴连续身份、角色与业务背景；不复制素材和承诺。
- [Relevance AI](https://relevanceai.com/)：借鉴能力评估、过程与治理可查；不把工程配置作为首页。

这些相邻产品不足以证明完整覆盖本项目主线，不宣称全球首创。

## 设计评审点

本次止于 UI 原型。评审应观察未看文档的客户能否找到三动作、解释晓禾何时获得资格，以及第三人为什么建组。当前截图与自动化测试不是实际用户访谈的替代。
