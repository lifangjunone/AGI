## Semantica 实际接入

隔离 Python 3.11 环境安装 `semantica==0.7.0`，依赖锁定在 `backend/requirements.lock.txt`。

真实调用：

- `ContextGraph` 禁用自动提取和高级分析，构建来源/方法/条件节点以及 supported_by / applies_under 关系。
- `to_dict/from_dict` smoke test 验证图往返恢复。
- `ContextRetriever.retrieve(mode="local")`，只提供 SQLite 已过滤的员工授权子图，一跳关系。

联调发现：

1. 发布版关键词回退分支搜索实体 `name`，不是图节点 `content`。适配器从真实图序列化结果映射 `entities/relationships`，明确提供可检索名称。
2. 该版本 `use_graph_expansion=False` 会完全跳过图检索，不是只关闭邻居展开。改为 True 并限制一跳，而且输入已经是授权子图。
3. 中文查询按字符/关键词适配；目标无匹配时查询允许的 method/condition 基线，不查询全库。

SQLite 是权威持久化，图按授权请求重建。没有冒充向量语义检索，没有安装 Graphify、AI Town 或 ai-job-search 为运行依赖。

## 模式诚实与限制

演示模式：确定性规则与模板，真实落库、资格门禁与调度，不代表模型学习。

真实模式：服务端 OpenAI-compatible JSON 模型适配，教学/考试/试岗/职责产物调用，引用范围和正文标记校验，45秒超时，不静默回退。没有使用用户密钥做供应商验证，错误路径用模拟测试验证。

首版组队决策是能力/授权/负载规则，不是自由 Agent 对话驱动的无限自治。所需技能由发布者选择，员工在执行里补齐职责。

独立评审是结构、引用有效性与目标一致性规则，不等于业务质量评分或独立模型意见。考试同样为有限规则，演示资格不推广到真实模式。

本地单工作空间，无生产认证。全工作空间页面供本地操作者管理，但员工检索上下文仍按受众过滤；不能宣称跨用户/多租户安全。任务输入经发布者确认供执行成员使用，个人方法授权不自动扩散给队友；派生产物向本地授权操作者展示，生产共享治理仍需后续设计。

资料撤回阻止后续检索、资格失效、在途运行阻塞并标记产物；已输出历史正文与外部模型已处理资料不承诺彻底回收。
