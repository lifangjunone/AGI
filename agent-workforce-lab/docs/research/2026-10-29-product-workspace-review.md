# 双入口产品改进：从宣传页面到实际工作空间

调研日期：2026-10-29。仅核实公开页面内容，不把厂商宣传当作本项目已实现能力。

## 当前实现复盘

1. 缩小字号只处理了症状：页面仍在解释“产品是什么”，没有聚焦“我今天做什么”。
2. 运营首页仍能跳入教学，违背专门运营人员与员工端分离。
3. 学习列表是静态文章，点击不能切换，用户无法处理具体学习记录。
4. 目前所有组织员工在员工端可见，没有账号级“我的分身”归属隔离；产品文案不能替代权限。
5. 试岗仍是人填回答、规则打分；不能说数字员工已自主考试。
6. 任务仍由人点击更新与邀请，不等于 Agent 已自主执行。

## 本轮实际修改

- 运营首页改为考核、阻塞、验收队列，移除教学入口。
- 学习列表变成原生按钮，可选择具体记录、搜索主题或来源、筛选待处理与已确认。
- 回答与确认表单按记录 ID 隔离，避免切换后把旧内容提交到另一条记录。
- 教学确认明确交接运营考核，不再引导员工操作考试。
- 保留已确认的双入口与正常字号，不另换色或再造海报。

## 验收与下一道门槛

本轮需验证真实运行的多记录切换、筛选、两端交接、移动端和空状态。自动化应通过可见按钮和表单完成关键操作，而非只用 API 填满状态。

尚不具备最终产品完成证据：账号归属、授权撤回、低负担来源接入、真实 Agent 考核与运行、协作资格、逐能力回流、无障碍对话框仍需建设。

设计技能用于反模板复盘、状态忠实与截图检查；不采用其泛化营销 Hero，也不把技能搜索的无匹配结果说成精品调研。
