# 产品体验优化：数字校园工作台

日期：2026-10-25。仅修改本项目，旧 v4 原型保持不动。

## 北极星

**用户始终知道正在教谁、下一步怎么做、谁在完成任务、成果在哪里。**

保留暖纸、鼠尾草校园和墨绿动作，不转成管理后台。素材复用现有原创校园 SVG，没有引入外部资产或另做风格模板。

## 本次改动

- 教学分成「教与学 / 考试与试岗 / 知识档案」，减少一列长表单堆叠。
- 成长路径按已确认知识、考试记录、试岗和当前模式资格显示；确认理解后直接进入考核工作区。
- 资料导入与贡献者设置渐进展开，保留授权确认，主提交在桌面首屏可见。
- 任务发布增加可编辑脱敏例子、当前技能资格预览与发布前确认。
- 任务列表支持搜索、全部/待我处理/进行中/已完成筛选；员工名册可直接进入教学。
- 交付页区分「成果与验收 / 协作记录」，每个状态解释下一步，展示成员加入理由和时间。
- 产物支持下载 Markdown；历史版本、来源引用与受影响标记保留。
- 发布、验收、取消与授权撤回使用产品内确认弹窗，不依赖浏览器原生确认框。
- 中文评审检查名称代替工程字段，重复机器编号移入追踪详情。
- 教学、理解编辑与反馈草稿保留；轮询避免旧请求覆盖新状态，操作锁阻止重复提交，连接中断不清空输入。
- 按容器实际宽度重排校园，修复 200% 放大时只有页面不溢出、内部仍挤压的问题。

## 设计技能取舍

`ui-ux-pro-max` 用于 React 异步错误与状态建议、字号、触控和减少动效检查。渐进披露查询重试后仍返回无关标题建议，没有把它当作匹配结果；布局取舍依据现有规范、截图与 Oil UI 存量深化流程。

`oil-ui` 引导基线截图、层级减法、素材复用与独立评审。删掉重复身份介绍、英文大写空间标题和多处完整机器编号；未删除对象名称、资格边界、授权确认和任务版本。

动效：首次校园短出场、分区切换短位移、按钮按下与保存反馈；无等待动画门禁。减少动态效果保留全部内容。没有把纯装饰动画当作模型学习。

## 评审与证据

一轮独立存量润色评审，不打分。指出：

1. 200% 校园挤压 → 容器查询切换上下布局。
2. 主动作过远 → 压缩重复身份与说明，保留正常输入字号。
3. 机器编号重复 → 编号收进协作追踪详情，保留第三人成组与原任务连续性。

主 Agent 修改后重新截图复查；独立评审不等于真实客户可用性测试。

证据位于项目 `runtime/product-review/`：教学首屏、成长、发布、交付、成果、375/768/1024 与 200% 图，`checks.json` 记录失败/刷新/搜索/下载检查。

完整链路由 `tests/browser.cjs` 回归；新分区、发布确认和验收确认纳入测试。理解确认草稿另外实际修改后刷新读回。

最终改动后完整闭环连续通过 **3 次**，记录在 `runtime/product-final-1/`、`product-final-2/`、`product-final-3/` 的 `verification.json`。TypeScript `tsc --noEmit` 通过。失败/刷新/搜索/下载专项检查通过，未发现页面脚本错误。本轮未声称通过暗色模式、读屏认证、生产安全或真实客户理解测试。

## 范围边界

这是产品体验优化，不是生产认证完成。仍是本地单工作空间；演示模式为确定性模板，真实模型需服务端配置。规则考试与评审不宣称真实业务质量认证。

没有公网部署、AS 接入、共享 Nginx 修改或使用其他项目凭据。保留现有后端权限门禁和积分事务，本轮不做无关业务重构。
