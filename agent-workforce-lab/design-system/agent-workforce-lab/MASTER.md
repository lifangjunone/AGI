## 当前设计方向：可观察的数字员工广场（v2）

用户否定了 v1 看板方向，明确要求参考所给广场图片，直观显示自主组队和独立完成任务。v2 采用暖纸底、鼠尾草地面、柔和等距建筑与可点击角色，空间占首屏主体，观察面板与任务池支撑行动。

入口：`design/prototype/plaza.html`。v1 `index.html` 留作对照，不再是推荐首页。

- 六个空间：知识馆、学习与考核站、任务公告栏、组队工坊、独立工作室、交付中心。
- 两条过程：团队任务展示能力匹配、邀请、协作、提交；单人任务展示完整覆盖、独立认领、执行、提交。最终均需真人验收。
- 员工名称、职责、行动气泡与观察面板配合；点击可查看知识背景和资格。位置表达工作步骤，不冒充物理位置。
- 技能重新检索 `virtual world spatial collaboration --design-system`，匹配的沉浸体验模式有用，但 VisionOS 玻璃和 VR 样式不适合参考图；以 `isometric simulation game` 收窄后仍未命中，等距广场采用用户参考驱动的原创构图，未使用营销 Hero 模板。
- 核验 `dragging movements --domain ux`：空间不依赖拖拽，采用按钮和等价列表。小屏默认列表，可切换空间。
- token：背景 #F5F2E9、纸面 #FFFDF7、文字 #263D39、次文字 #65746B、动作 #315B47。建筑色只区分空间，不独自承载状态。
- 建筑和人物用可交互 CSS 层组合，非栅格截图；路径与邀请关系用 SVG。无第三方素材或已有项目源码复制。
- 动效：一次进入淡入、按钮反馈、工作步骤位置迁移；用户控制播放／暂停，隐藏页面或弹窗打开时不推进，减少动态效果时位置直接到位。
- 所有步骤是设计演示，不接 SDK／模型／数据库，关键真权限仍由未来后端落实。

## 历史设计方向：数字员工工作室（v1）

面向知识贡献者与内部项目负责人的桌面 Web。使用简洁网格、清晰的信息层级与可核查的证据；协作现场有空间感，但不以小镇动画取代工作成果。浅色界面、深蓝侧栏、青绿色主动作，暖灰背景降低长时间阅读负担。

## 技能使用与适配记录

已使用 `ui-ux-pro-max` 的 `--design-system`，查询 `enterprise knowledge workforce dashboard`，再以 `operations dashboard` 收窄重试。

- 已核验匹配：Minimalism & Swiss Style 适用于 enterprise apps / dashboards；清晰层级、少装饰、文字状态、焦点、减少动态效果。
- 未采用：两次推荐的营销 Hero / CTA / Conversion 页面模式均不匹配任务工作空间。没有已验证的页面模式匹配，信息架构采用 PRD 驱动的设计判断，不将其伪装为数据库匹配。
- 青绿、暖灰、深蓝组合是产品设计调整，不是技能原始配色的照搬。主要前景／背景组合须验证对比度。
- 字体采用本机中文无衬线，不加载第三方字体；英文数字可用系统等宽字体。
- 已查询 `keyboard focus modal --domain ux` 与 `state forms accessibility --stack react`：使用语义按钮、标签、可见焦点，后续 React 表单受控；不因技能推荐而增加框架依赖。

## 导航与布局

桌面侧栏 224px，内容最大宽度 1440px，左右内边距 32px。一级导航四组：工作总览、知识与人才、工作与交付、治理。总览提供完整生命周期、一个主要行动、当前协作现场和真人待办。

≥1024px 双栏／三栏；768–1023px 缩窄侧栏、内容双栏；<768px 侧栏变为顶部可折叠导航，主体单栏。375px 不产生整页横向滚动；复杂图使用纵向节点列表。移动端不把八项导航硬塞进底栏。

## 组件与状态

- 卡片：标题、依据、状态、行动；避免可点击容器内嵌按钮。
- 状态：通过／待核分／阻塞／需复核／未接通，同时写文字，不能仅依赖颜色。
- 模式：持续标注“UI 原型 · 样例数据”；SDK、模型显示未接通，不能显示假健康。
- 资格：展示技能、分数、有效条件；积分不表现为资格进度。
- 来源：使用原文引用与位置、确认性质、用途和受众，敏感字段不展示。
- 图谱：节点按钮可打开来源，提供列表切换；不能只靠拖拽、悬浮或颜色读取。
- 弹窗：原生 dialog、明确关闭/Escape、初始焦点、关闭后返回触发点，内容可滚动；删除／撤回需二次确认。
- 表单：可见标签、字段错误、失败保留输入；无后端的提交只演示并明确提示不保存。
- 动效：背景／边线 160ms，非必要动画关闭；不做闪烁状态、自动播放、强制滚动。

## 原型与实现分界

`design/prototype/` 为独立静态 HTML/CSS/JS 设计原型，不是 React 应用。只模拟导航、来源查看、图／列表切换、样例核分、验收与积分、撤回影响；刷新恢复初始样例。无 API、无持久化、无真实身份或权限保证。所有真实门禁依 PRD 在后续后端实现。

UI 评审确认后，再将原型布局转为 React/TypeScript 组件，使用后端契约驱动状态，不复制原型样例逻辑作生产引擎。
