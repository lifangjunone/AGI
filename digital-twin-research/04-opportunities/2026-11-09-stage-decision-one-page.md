# 数字分身阶段决策：价值来源与继续路线

日期：2026-11-09
阶段：S1 问题收敛 -> S2 客户验证
结论：没有已证明的产品方向；停止扩展桌面调研，只保留一条可证伪业务逻辑

## 决策

1. **停止通用数字分身平台。** 不建设“上传资料即可复制一个人”的通用产品，
   不以形象、声音、语气或人格相似度作为核心价值。
2. **冻结通用企业知识传承和客户交接。** 问题真实，但检索、访谈、培训、
   交接摘要、技能矩阵和人工审核已被成熟产品覆盖；当前没有独立预算证据。
3. **继续且只继续“低责任作品反馈中的专家身份增量验证”。** 用相同知识、
   相同输出、相同价格，分离匿名 AI、具名 AI、匿名专家签认和具名专家签认，
   只看真实付款和重复使用。
4. **在结果成立前不孵化平台。** 当前动作是验证业务逻辑，不是开发产品。

## 数字分身靠什么创造价值

价值公式：

`可量化任务改善 × 可信度 × 使用频率 - 获客、人工复核、授权与合规成本`

| 可能价值 | 当前判断 | 含义 |
| --- | --- | --- |
| 更好、更快完成具体任务 | 必须成立 | 用户买结果，不买“有一个分身” |
| 稀缺判断可重复交付 | 值得验证 | 把专家判断用于具体作品，而非泛问答 |
| 来源、边界和版本可追溯 | 必要但不独占 | 是可信交付基础，已有大量替代品 |
| 真人承担最终签认责任 | 有市场先例，增量未知 | 可能降低信任成本，但会增加人工成本 |
| 特定真人姓名和方法 | 核心未证假设 | 必须证明比匿名同质量输出带来额外付款或留存 |
| 高拟真头像、声音、语气 | 无价值证据 | 只能作为界面，不得作为商业逻辑 |

因此，数字分身只有在“同样内容下，身份或签认带来可重复的经济增量”时才是
独立产品类别；否则它只是知识库、AI 助手或人工服务的品牌包装。

## 唯一值得继续的业务逻辑

**产品假设：可验证专家反馈。**

- 用户：愿意为小说片段、演讲练习或摄影作品反馈付费的创作者。
- 任务：获得具体、可执行、低责任的下一轮修改建议。
- 交付：AI 基于已授权专家材料生成草稿；只有实验指定输出由专家本人按统一
  rubric 签认；每条结果保留来源、版本、审核者和修改记录。
- 收费：先按次真实付费，不做订阅，不依赖专家私域名单。
- 界面：优先文本或结构化反馈，不开发数字人形象、声音或实时 Avatar。
- 核心变量：身份展示和本人签认，而不是模型能力或不同内容质量。

这条逻辑值得继续，不是因为它已经成立，而是因为它同时满足：变量可隔离、
结果可收费、责任较低、可快速否证，并能直接回答“数字分身是否有独立价值”。

## 晋级与停止

| 结果 | 决策 |
| --- | --- |
| 具名相对匿名产生可复现的真实付款和重复使用增量，且完整贡献毛利为正 | 继续孵化专家身份产品 |
| 只有专家签认有效，姓名无增量 | 转为通用人工签认服务，不再称数字分身 |
| 姓名有效但签认无增量 | 只保留品牌授权模式，验证可持续授权成本 |
| 身份和签认均无增量 | 停止 Track C，不建设产品 |
| 专家授权、40 次容量、中立获客或图片权利无法通过 | 记录供给侧不可执行，不降低门槛 |

## 下一阶段边界

1. 停止新增专家长名单和公开页面深挖；P05、P06、P02 的现有证据足以说明
   供给阻断。
2. 在获得外联授权前，只整理一份候选资格差距矩阵，不继续研究价格和日历。
3. 获批后先验证一名专家的交易、授权、本人容量和匿名接受；失败即停止该垂直。
4. 只有一名专家通过供给门禁，才运行候选级中立渠道预筛。
5. 只有供给、渠道、单位经济和隐私同时通过，才冻结并执行 X-012A。
