# X-012：真人身份必要性与付费溢价

日期：2026-11-09
状态：待真实专家与付费受众
前置结论：机会重置后没有候选达到晋级门槛；本实验验证数字分身定义中最基础、此前未被证明的商业假设。

## 假设

在内容、交互、服务水平和风险边界相同的情况下，用户会因为建议来自某个特定真人专家的授权分身而：

1. 更愿意真实付费。
2. 支付更高价格。
3. 在 30 天内重复使用。

实验同时区分两种可能被混淆的价值：

- **身份溢价**：特定专家姓名、经历和方法带来的增量。
- **签认溢价**：答案经过真人专家复核并承担责任带来的增量。

如果只有签认溢价，没有身份溢价，成立的是专家验证服务，不是数字分身产品。

## 禁止使用的证据

- “听起来很酷”或“愿意试试”。
- 免费注册、页面停留或满意度。
- 专家本人对其品牌价值的估计。
- 厂商自报收入、活跃度或案例。
- 不同内容质量、响应速度或价格之间的横向比较。

## 样本

- 3 名已有付费产品或咨询客户的真人专家。
- 每名专家至少 80 名从无研究报酬的中立商业流量取得的真实参与者。
- 总样本至少 240 人，每个实验单元至少 60 人。
- 排除既有客户、只因参与补贴而来、从未购买过相邻服务的职业测试者。

专家必须满足：

- 有可授权使用的原创内容、方法和过往问答。
- 能定义明确的回答边界和禁止项。
- 愿意复核一部分答案并保留修改记录。
- 接受主样本不使用其自有名单或粉丝渠道，由中立运营方执行同等曝光的付费报价。

## 2×2 实验

所有组使用相同界面、底层资料、问题范围、响应时限和基础价格。

| 组别 | 特定专家身份 | 真人签认 | 用户看到的产品 |
| --- | --- | --- | --- |
| A | 是 | 否 | 授权的专家 AI，答案带来源但未逐条复核 |
| B | 否 | 否 | 匿名知识代理，使用同一资料与工作流 |
| C | 是 | 是 | 特定专家 AI，关键答案由本人复核并签认 |
| D | 否 | 是 | 匿名知识代理，关键答案由同资历专家复核 |

参与者随机分组；不得让高意向客户只进入 C 组。专家本人不能挑选组别。

## 真实支付

每组必须执行真实、可退款的付费动作：

- 首月访问费，或
- 单次问题费，或
- 专家签认升级费。

最低支付金额必须同时产生真实支付摩擦并覆盖保守变量成本。报价按[统计功效与单位经济审计](../02-projects/2026-11-09-x012-power-and-unit-economics-audit.md)中的成本底价计算，不再机械使用人工咨询价格的固定百分比。不接受“留下邮箱”“点击购买”或无资金冻结的意向按钮代替。

首轮四组价格必须相同，因此首轮只检验付费转化，不检验价格溢价。只有首轮身份主效应通过后，才能用新参与者执行独立价格确认波次；不得用问卷愿付价格推断 30% 溢价。

从首次渠道曝光到 `paid_72h` 锁定，不提供或承诺研究报酬，不报销购买，也不发放购买返现。研究面板样本只可用于预筛和流程测试，不进入主终点。详细门禁见[中立招募与真实支付审计](../02-projects/2026-11-09-x012-neutral-recruitment-audit.md)。

## 核心指标

1. 各组真实付费转化率。
2. 身份主效应：A 对 B、C 对 D。
3. 签认主效应：C 对 A、D 对 B。
4. 身份与签认的交互效应。
5. 30 天重复使用率、退款率和真人升级率。
6. 每个付费用户的专家复核分钟数和毛利。

主分析在实验启动前预注册，使用专家分层的二项回归估计身份、签认及交互效应；不得在看到结果后更换主指标或合并组别。

## 两阶段通过标准

X-012A 维持 3 名专家、240 名参与者，只验证汇总真实付费主效应和首轮经济可执行性。必须全部满足：

1. 三名专家中至少两名出现方向一致的身份差，且单一专家正向贡献不超过 70%；这只是跨专家一致性检查，不构成专家级复现。
2. 首轮统一价格下，显示特定专家身份使真实付费转化率提高至少 20 个百分点。
3. 价值不能完全由签认解释；若 C 优于 D，但 A 不优于 B，只能证明专家签认价值。
4. 至少一名专家的 C 组在计入复核、退款、专家分成、获客和支持成本后仍有正贡献毛利。
5. 严重越界、身份泄漏和退款未触发停止规则。

X-012A 通过只允许进入 X-012B，不允许宣布产品假设成立。X-012B 必须使用新参与者，预先计算足以检验 30 天留存差异的样本，覆盖至少两名不按首轮效果挑选的专家，并形成跨专家与正毛利确认。之后仍须证明 Delphi、Coachvox、BuddyPro 或现有专家市场不能低成本复制差异。

如果后续声称存在 30% 价格溢价，必须再由独立随机价格波次证明，不能与 X-012A 或 X-012B 混合解释。

## 否决项

- 匿名代理与专家分身的付费和重复使用无实质差异。
- 用户只为真人签认付费，不在意是哪位专家。
- 购买主要来自对专家既有课程或社群的捆绑，无法独立定价。
- 专家复核成本使毛利为负。
- 高风险问题频繁越界，且不能通过范围、拒答和转接控制。
- X-012B 无法在至少两名专家上确认方向、留存和经济门槛。

## 结果解释

| 结果 | 解释 | 后续 |
| --- | --- | --- |
| X-012A 身份与签认均有增量 | 只形成付费筛选信号 | 进入 X-012B 留存与跨专家确认 |
| 只有身份有溢价 | 品牌/粉丝产品成立，治理价值弱 | 与 Delphi 等现有平台做配置成本比较 |
| 只有签认有溢价 | 专家验证服务成立，不是数字分身 | 转向人类专家验证市场，不继续分身产品 |
| 两者均无溢价 | 真人复制没有独立经济价值 | 淘汰当前数字分身产品孵化方向 |

## 启动门禁

在取得 3 名专家、通过中立渠道预筛、真实报价和支付通道前，不开发专用平台。实验可先用现有表单、支付、严格知识库和人工签认完成，但每个答案必须来自真实资料并保留来源、版本和复核记录。
