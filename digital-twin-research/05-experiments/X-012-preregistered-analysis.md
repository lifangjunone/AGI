# X-012 预注册分析与停止规则

日期：2026-11-09
状态：草案锁定；需在首名参与者分配前生成只读版本和时间戳

## 研究问题

在内容、功能、价格和服务水平相同的情况下：

1. 显示特定专家身份是否提高真实支付？
2. 真人签认是否提高真实支付？
3. 身份与签认是否存在交互效应？
4. 身份是否提高 30 天重复使用，并在计入人工成本后保留正毛利？

## 主要终点

`paid_72h`：参与者首次看到报价后 72 小时内，由支付机构确认成功支付。

采用 ITT（Intention-to-Treat，意向治疗分析，即所有已随机分配者都按原组分析），不因未打开、未使用、退款或跨组污染而删除。

## 次要终点

- `net_paid_d8`：第 8 天仍未退款。
- `repeat_use_itt_30d`：所有随机参与者中，30 天内至少在两个不同自然日提交有效问题或作品；未付款或未使用者记为 0。
- `payer_repeat_30d`：付款者中的重复使用率，只作运营指标，不作随机化因果解释。
- `question_count_30d`：30 天有效提交数。
- `refunded_7d`：7 天内退款。
- `escalated_30d`：购买真人升级。
- `correction_rate`：发布前后需要专家纠正的答案比例。
- `review_minutes_per_payer`：每个付费用户的真人复核分钟数。
- `contribution_margin_per_payer`：每个付费用户的贡献毛利。

满意度、打开来源和自报购买原因只用于解释，不能替代主要终点。

## 主要比较

| 效应 | 比较 |
| --- | --- |
| 身份主效应 | A+C 对 B+D |
| 签认主效应 | C+D 对 A+B |
| 交互效应 | `(C-A) - (D-B)` |
| 无签认身份效应 | A 对 B |
| 有签认身份效应 | C 对 D |

主要成功判定以身份主效应为准。A 对 B 和 C 对 D 是预先规定的解释性分解，不单独替代主效应。

## 模型

主要模型使用二项回归，包含：

- `identity`
- `signoff`
- `identity × signoff`
- 专家固定效应
- `relationship_stratum`
- `recent_need`
- `channel`

只使用三名专家时不估计专家随机效应，因为群组数量不足。报告模型边际标准化后的绝对风险差、相对风险和 95% 置信区间，不只报告比值比或 p 值。

每名专家另行报告 A+C 与 B+D 的原始转化差。单个专家样本不足以要求统计显著；至少两名专家同方向且不由一个极端样本完全驱动，只是跨专家一致性检查，不得称为独立复现。

单一专家正向贡献占比定义为 `max(0, Δe) / Σ max(0, Δe)`，其中 `Δe` 为该专家身份组与匿名组的原始付费率差。分母为 0 时直接失败。

另按 `aware_nonbuyer` 和 `unaware_adjacent_buyer` 报告身份效应。该分层用于解释，不替代总体主要终点：

- 只在 `aware_nonbuyer` 有效：专家声誉可能产生获取增量，但需要已有认知渠道。
- 在 `unaware_adjacent_buyer` 仍有效：需检查是否由履历信息而非身份本身造成。

任何 `prior_buyer` 探索队列必须独立报告，不进入模型、主终点或通过判定。`prior_expert_ai_exposure=1` 的参与者不得进入正式随机化；若误入，按重大协议偏差保留原始记录但不用于证明身份主效应。

## 样本解释

240 人是首轮最低可执行样本，不保证对每名专家的单独效应有充分统计功效。它可以估计汇总身份主效应并检查跨专家方向。

不得：

- 因中期差异不明显而提前结束。
- 在看到分组结果后扩样到“刚好显著”。
- 合并某些组或删除表现不利的专家。

如招募不足 240 人，实验记为未完成，不作通过判定。可报告描述性结果，但不能升级产品方向。

## 缺失与排除

ITT 主分析只排除：

1. 未成年人。
2. 重复身份或确认欺诈。
3. 执行团队、专家团队或其直系亲属。
4. 支付机构确认的测试交易。

排除原因必须在解盲前固定。页面未打开、支付失败、没有提交、退款和失访都保留。

次要的 per-protocol（依方案完成者）分析可以排除从未加载购买页或确认未收到邀请者，但必须标为敏感性分析，不能推翻 ITT 结论。

## 多重比较

唯一确认性检验是身份主效应对 `paid_72h` 的影响，双侧显著性水平 0.05。

签认、交互、净付费、重复使用、退款和毛利是预先规定的次要结果，报告效应量与区间，不用多次尝试后的单个显著结果宣布通过。当前样本对专家级效应、交互和低基线留存没有确认性功效。

## 毛利

贡献毛利按实际现金计算：

`实收收入 - 退款 - 税费 - 支付费 - 持续专家分成 - 模型与存储成本 - 专家复核分钟 × 分钟成本 - 渠道获客成本 - 参与者支持成本`

不把专家无偿劳动计为零成本。专家分钟成本在实验前按其人工服务的隐含时薪和书面完全成本时薪中的较高值锁定。一次性研究开发和运营标为 `experiment_subsidy` 并单独报告，不混入稳态贡献毛利；持续授权费或收入分成必须计入变量成本。

## X-012A 通过标准

X-012A 首轮必须全部满足：

1. 至少 240 名合格参与者完成随机分配，每组至少 60 人。
2. 汇总身份主效应的绝对付费转化提升至少 20 个百分点，且 95% 置信区间不跨 0。
3. 三名专家中至少两名的身份差方向为正，且单名专家正向贡献不超过 70%；该项不构成专家级复现。
4. 主样本全部来自无研究报酬的中立商业流量；面板奖励、购买补贴和专家自有名单参与者均未进入主终点。
5. A 对 B 不能为零或负而只靠 C 对 D 形成优势；否则只能解释为签认或品牌与签认交互。
6. 至少一名专家的 C 组在完整计入变量成本后贡献毛利为正，且实验补贴单独披露。
7. 严重越界、身份泄漏和退款未触发停止规则。

30 天重复使用只作探索性结果。X-012A 通过只允许进入使用新参与者、功效至少 80% 的 X-012B 留存与跨专家确认；X-012B 未完成前不得宣布身份必要性产品假设成立。

30% 价格溢价不属于 X-012A 或 X-012B 通过标准，必须由独立价格确认波次证明。

## 立即暂停规则

任一专家样本出现以下情况立即停止新增参与者，保留既有记录：

- 高风险越界内容达到 2 次，或任何一次造成现实伤害。
- 匿名组身份泄漏率超过 10%。
- C/D 组中任一组超过 20% 的答案未在承诺时限内完成复核。
- 四组价格、额度或页面发生不可追溯的不一致。
- 专家要求定向分配、删除负面记录或查看中途分组结果。
- 退款率超过 30%，且退款原话集中指向误导性身份或签认描述。
- 数据泄露、无权使用材料或支付并未真实到账。

修复后只能以新版本、新时间戳和新参与者重启；不得把中断前后样本无说明合并。

## 淘汰解释

- 只有签认主效应：转向专家验证服务，不称为数字分身。
- X-012B 只有某一专家有效：视为单一品牌生意，不形成可复现产品。
- 付费有效但无重复使用：视为一次性好奇或支持性购买。
- 身份有效但毛利为负：不进入 X-012B。
- 身份无效：停止当前数字分身产品孵化，把身份降级为可选包装层。

## 启动门禁

首名参与者分配前必须全部存在：

- 3 名通过资格核验并签署授权的专家。
- 每个垂直至少 50 份独立渠道预筛和经批准的 240 人现金预算；预筛样本不进入正式实验。
- 锁定的材料快照、范围、拒答与复核 rubric。
- 四组逐像素等价页面和真实支付通道。
- 冻结的随机序列、数据字典、成本口径和分析文档。
- 每名专家至少 5 份计时复核校准、成本底价和实验补贴预算。
- 支付、退款、隐私、作品授权和研究伦理书面审查，以及任何面板外部结账的书面平台批准。
- 退款、删除、身份泄漏、越界与人工升级流程的端到端测试记录。

任一项缺失，状态保持“待招募”，不得用演示数据或内部人员启动。
