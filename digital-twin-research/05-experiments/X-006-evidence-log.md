## 采购与试点信号

“感兴趣”“可以看看”不计为预算信号。

| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |

信号强度：

- `0`：没有下一步。
- `1`：同意再次访谈或看方案。
- `2`：愿意提供脱敏数据或安排专家、接班人。
- `3`：确认预算路径并同意书面试点范围。
- `4`：付费试点、采购意向或已批准预算。

能力值只允许填写：

- `已证明`：受访者展示实际界面、流程或输出。
- `自述可用`：受访者明确使用过，但未展示。
- `厂商声称`：仅来自销售或公开资料。
- `未覆盖`：受访者确认当前流程没有该能力。
- `未知`：没有足够证据。
