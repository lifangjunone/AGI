# 设备检修工单管理系统规格

## 范围

第一期交付一个可本地运行的 Web 系统，覆盖工单登记、查询筛选、统计、详情和状态跟踪。

## 自动决策

- `DEC-WO-001`：已关闭不计入“已完成”，单独保留关闭状态。
- `DEC-WO-002`：编号采用 `WO-YYYYMMDD-NNNN`，每日从 `0001` 递增。
- `DEC-WO-003`：实现待接单、处理中、已完成、已关闭完整流转。
- `DEC-WO-004`：紧急工单显示“两小时响应”提示，本期不实现定时通知。

## 需求与业务规则

| 需求 | 描述 | 业务规则 |
|---|---|---|
| REQ-WO-001 | 列表展示编号、标题、设备、站点、优先级、状态、负责人和截止时间 | BR-WO-001 |
| REQ-WO-002 | 按编号、标题或设备关键词查询 | BR-WO-002 |
| REQ-WO-003 | 状态与优先级组合筛选，条件为且关系 | BR-WO-003 |
| REQ-WO-004 | 展示全部、待接单、处理中、已完成数量 | BR-WO-004 |
| REQ-WO-005 | 调度员创建工单并校验必填项 | BR-WO-005 |
| REQ-WO-006 | 自动生成编号，默认待接单且负责人未分配 | BR-WO-006 |
| REQ-WO-007 | 查看工单详情和当前负责人 | BR-WO-007 |
| REQ-WO-008 | 支持接单、开始处理、完成和关闭 | BR-WO-008 |

## 规则定义

- `BR-WO-001`：列表字段完整，空负责人显示“未分配”。
- `BR-WO-002`：关键词对编号、标题、设备名称和设备编码执行不区分大小写的包含匹配。
- `BR-WO-003`：关键词、状态、优先级条件同时存在时执行 AND 组合。
- `BR-WO-004`：已完成统计仅统计状态为“已完成”，已关闭不计入。
- `BR-WO-005`：标题、设备名称、设备编码、站点、优先级和故障描述必填。
- `BR-WO-006`：编号为 `WO-YYYYMMDD-NNNN`；新建状态为待接单；负责人为空。
- `BR-WO-007`：详情显示摘要、完整故障描述、负责人、创建时间和状态。
- `BR-WO-008`：合法流转为待接单→处理中→已完成→已关闭；接单时填写负责人。

## 非功能要求

- 所有业务数据仅保存在本地。
- 刷新和重启后数据不丢失。
- 桌面和 1280px 以上浏览器可完整使用。
- API 错误返回结构化中文信息。
