# 状态盲盒照片生成

一个新的轻量子产品：用户上传自己的照片，选择风格模板，然后生成“豆包风格”的状态盲盒、镭射收藏卡、MBTI 注解卡和星夜油画肖像任务。

当前版本默认是“可演示 + 可接真实图像服务”的实现：

- 前端支持拖拽/点击上传照片、本地预览、选择多个模板。
- 后端校验图片大小和类型，构建结构化生成任务。
- 没有配置图像供应商时，返回可复制到图像模型的完整提示词。
- 配置 `IMAGE_PROVIDER=openai` 和 `OPENAI_API_KEY` 后，会调用 OpenAI Images edit 接口，使用用户上传照片作为参考图并返回图片结果。
- 默认不保存用户原图，不写入磁盘；生成接口只返回图片指纹前 16 位用于去重/调试。

## 已选定的界面

2026-11-17 用户选定 A「收藏卡展柜」。正式入口保留蓝灰展台、叠放收藏卡、右侧紧凑制作区，并支持六种风格。

- 点击生成立即跳转 `/status-capsule/result.html`，在独立作品页发起生成请求并显示等待、失败与重试。
- 提示词默认折叠。只有真实 `imageUrl` 才展示下载按钮；没有模型配置时明确标注参考图不是用户作品。
- 浏览器 IndexedDB 保存当前标签页的照片、偏好和结果，用于返回修改和刷新恢复；过期时间两小时，过期记录在再次打开产品时清理。
- 首页提供“清除本机照片与草稿”按钮，可立即删除本标签页对应的照片、作品与草稿。服务端仍不保存原图。
- 刷新未完成的生成不会自动重复调用，需用户确认重试。

参考图片来自用户提供的附件，仅用于风格展示。本地 UI 验证覆盖 1440、1024、768、375px，真实提示词 API 流程，以及模拟图片成功分支；未进行真实付费图像生成。

## 接图像模型

OpenAI 图像模型示例：

```bash
IMAGE_PROVIDER=openai OPENAI_API_KEY=你的key npm run dev
```

可选环境变量：

```text
OPENAI_IMAGE_MODEL=gpt-image-1
```

`src/generator.mjs` 已把每个模板输出为结构化 job。接入真实供应商时可以在 `buildGeneration` 后增加 provider client，把：

- `photoDataUrl`
- `job.prompt`
- `job.negativePrompt`
- `job.aspect`

传给对应图像生成/图生图接口，并把 `job.output.imageUrl` 替换为真实结果地址。

建议保持现有隐私策略：除非用户明确保存作品，否则不要落盘原图。
