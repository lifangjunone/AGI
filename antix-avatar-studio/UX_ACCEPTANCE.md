## 不足与后续验收

1. **照片生成数字人未完成。** 当前 `aliveAvatar` / `studioIdentity` 使用原照片、
   CSS 光效与动画；不是图生数字人、表情生成或口型驱动。应接入真实生成链路，
   创建/编辑面板现已明确标注照片风格预览，手机基础配置提示首屏可见。
   仍需接入真实生成链路，不能用说明修正替代“生动数字人”要求。
2. **实时语音全链路未完成。** MaaS TTS 已接入，但浏览器收音仍受
   `Permissions-Policy: microphone=()` 限制；浏览器 SpeechRecognition
   模拟事件不是实时会话验收。需要产品范围的麦克风策略与实际设备测试。
3. **真实统一账号端到端未验收。** 已验证游客 SQLite 保存和独立浏览器
   恢复，以及模拟账号隔离；需要用户提供测试账号或登录测试空间，验证登录、
   注册返回、跨设备恢复、会话失效与账号切换。禁止拿游客测试代替。
4. **真实收款闭环未验收。** 手机人工核款接口与付费 UI 存在，尚需真实
   ¥0.9 支付、管理员核对、开通、7 天到期与手动续费验收。任何测试不得
   伪造到账或未经授权确认真实订单。
5. **国际化未全面验收。** 默认中文与部分英文页面已验证；已为用户内容
   增加翻译排除边界并验证重点页面。旧翻译字典、其余动态文案与混合用户/
   界面文本仍需逐页核对，避免遗漏中文或错误翻译。
6. **真实设备输入/辅助技术未验收。** 合成 IME 事件、视口截图和焦点语义
   不能替代系统中文输入法、软键盘遮挡、屏幕阅读器和文字放大测试。
7. **跨标签并发保存已有保护。** 2026-10-30 已加事务内版本校验，
   旧快照返回 409，缺版本的旧页面返回 428；冲突提供本页快照导出与
   加载最新配置。真实游客 SQLite/API 双页面验收通过。尚无自动合并，
   导出包含提交快照和导出时仍打开的产品表单字段、照片、风格选择；
   加载最新配置前也会尝试本地备份，失败则停止。尚无自动合并或备份导入。
   `20261029T211458Z` 在数据库写锁内分配严格递增版本，固定或回拨时钟
   不会复用旧版本；独立连接同时写测试仅一个请求成功，随后连续保存正常。
   线上真实游客 API 双标签冲突及无缓存分身人格恢复复测通过，非登录账号验收。
