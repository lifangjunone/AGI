# 设计说明

- 用户任务：建立多个数字分身，用长期记忆塑造人格，并让分身承担对话与内容创作。
- 产品名：Second Me。
- 产品结构：总览、分身库、实时工作室、记忆库、内容创作、设置六个独立工作区。
- 国际化：简体中文与 English，首次访问默认简体中文，选择本地持久化。
- 主动作：创建分身 → 训练记忆 → 对话或生成内容 → 保存并持续积累。
- 方向：电影级数字人实验室。延续青蓝/洋红霓虹人物主视觉，并用低饱和仪器界面承载高频工作流。
- 关键状态：多分身增删改、记忆增删与导出、连续对话、语音状态、内容生成、全局搜索、数据重载。
- 动效：页面进入、人物扫描、语音激活反馈与全局提示。
- 设备：桌面侧栏工作台优先；760px 以下切为抽屉导航和单列任务流。
- 验收重点：每个导航入口均可完成任务；刷新后读回；无横向溢出；中文信息可读。
