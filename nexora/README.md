# Nexora

Nexora 是一个本地优先、证据驱动的多 Agent 自主协作控制台。它把高层目标转换为可执行任务图，让不同角色的 Agent 并行认领、交接、评审和沉淀经验，并在高风险动作前保留明确的人类控制权。

## 当前能力

- 依赖驱动的任务图，支持自动解锁、并行认领和周期推进。
- 持久 Agent 身份，展示角色、专长、负载、信任度和记忆规模。
- 观察、协作、自主三级运行模式。
- 独立质量评审与高风险人工批准门禁。
- 不可变事件流风格的协作记录，以及带重要度的共享记忆。
- 新任务创建、本地持久化、暂停、恢复和演示数据重置。
- 指挥中心、任务图、团队和共享记忆四个工作视图。
- 桌面与移动端响应式布局，支持减少动态效果偏好。

当前版本使用确定性本地任务引擎，无需 API Key 即可完整演示。外部模型、CLI、沙箱和远程运行时属于下一阶段接入边界。

## 运行

```bash
cd nexora
npm install
npm run dev
```

默认开发地址：

```text
http://127.0.0.1:5173
```

## 验证

```bash
npm test
npm run build
```

## 设计来源

详细能力矩阵、取舍和来源见 [`docs/research.md`](docs/research.md)。

核心借鉴：

- Raft：持久 Agent 身份、共享频道、任务认领、Agent 间交接。
- Multica：完整任务生命周期、统一运行时、可复用技能、自托管。
- AI Town：共享全局状态、事务化输入、事件循环、记忆与反思。
- CrewAI：角色化团队、事件驱动 Flow、状态管理和任务门禁。
- LangGraph：持久执行、检查点、恢复和人在回路。
- AutoGen / AG2：可组合群聊编排、工具调用和人工介入。
- MetaGPT：标准作业流程与结构化中间产物。
- CAMEL：大规模 Agent 社会、动态通信和角色协作。
- OpenHands：模型无关运行时、隔离沙箱和可扩展执行基础设施。

Nexora 不复制这些项目的源码或视觉资产，只吸收公开机制并形成独立实现。

## 安全边界

- 不在前端保存模型凭证。
- 高风险任务不能由执行 Agent 自行批准。
- “完成”必须关联产物并经过独立门禁。
- 后续运行时接入应默认使用隔离工作区、最小权限和网络白名单。
